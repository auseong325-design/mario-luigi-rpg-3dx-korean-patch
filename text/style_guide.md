## 2. 공통 규칙

### 2.1 문장부호 (DS FEvent 전체 통계)
- 말줄임은 `…` 한 글자만 쓴다(2,001회). `...`와 `..`는 0회다. 뒤에 말이 이어지면 `…` 다음을 한 칸 띄운다(띄움 339회, 붙임 19회). `…!`와 `…?`는 쓰지만 `!…`는 쓰지 않는다.
- 기본 강도는 `!!`(1,302회)와 `!!!`(114회)다. 겹부호는 항상 `!?`(211회)이고 `?!`와 `??`는 0회다. 외침은 DS가 더 늘리기도 했다: `なんだと！！` → `뭐라고!!!!`(DS218#46).
- `~`(1,198회)는 JP `～`와 말꼬리 늘임에 쓴다. 낱말 가운데를 늘이기도 한다: `ごめんなさ～い！！！` → `늦어서 미아~안!!!`(DS218#7), `잘~ 알겠느냐`(DS20F#4).
- `―`(U+2015)는 비명·구령의 긴 끝(`イヤーー！！ あなたーー！` → `꺄악―――!! 여보―――!` DS09C#12, `공격 개시다―!`)과 의태어(`슥― 하고`)에 쓴다. JP 장음 `ー`는 `~`나 `―`로 늘이거나 느낌표로 흡수한다: `なにーーーーー！！` → `뭐라고!!!!!`(DS1FB#5).
- 마침표 `.`는 차분한 평서문, 설명, 표지판에만 쓴다(979회). 쉼표는 더듬기와 나열에 쓴다: `ど どうしたことだ…` → `어, 어떻게 된 거지…`(DS218#53). JP에서 공백으로 더듬으면 `내, 내가`처럼 쉼표를 넣는다.
- 기호 용도:
  - `♪`: 노래·흥얼(`롱롱롱~♪` DS0EB#5)
  - `♥`: 애교(DS025)
  - `×`: 개수(`슈퍼너트 × 5` DS078#1)
  - `( )`: 부속 이름(`파워 스페이스(팔)` DS01B#3)
  - `「 」`: UI 용어 강조(`우선 「배지」를 선택해!` MAI__MMes_yo)
- 뜻이 같은 DS 표지판은 화살표 뒤 공백도 해당 DS 문장 그대로 쓴다. DS08C#0의 `→비상구 입구로 연결됩니다.`는 붙이고, DS046#0·DS047#0·DS178#0·DS20C#0의 `↑ 숲 출구`·`↑ 고라파 레이크` 등은 띄운다. 신규 표지판에는 붙여 쓰기를 기본으로 권고한다. 전각 `！？～、。`는 쓰지 않는다. (review: 2026-10-06, AGENTS 0·4.6의 DS 동일 대사 보존 원칙 우선)

### 2.2 숫자
- 규칙·수량 설명은 아라비아 숫자와 단위로 쓴다: `２人で乗る` → `2명이 타야`(DS1F1#5), `{var}개째 획득했다!`, `나머지 … {var}개다!`(DS213#0).
- 문장 속의 작은 수·횟수·서수는 고유어로 쓴다: `もう１度` → `다시 한번`, `１人ぼっち` → `혼자`(DS1F1#6), `２つ目の` → `두 번째`(DS16E#1), `３人目の賢者` → `세 번째 현인`(DS16E#3), `１回だけ` → `한 번만`(DS099#1). 한자어 접두는 `第２の人生` → `제2의 인생`.
- 전각 숫자는 반각으로 바꾼다. `{var}` 뒤 조사 규칙은 AGENTS.md 4.1을 따른다.

### 2.3 띄어쓰기·표기
- 고유명사는 글로서리를 우선한다. DS 표기 예: 피치공주(붙임), 피치 성, 쿠파 성, 버섯 타운, 버섯 왕국, 스타 백신, 어택피스, 스페셜 어택, 뚱뚱데굴병, 헬로글로빈.
- `이름+님`은 붙인다(쿠파님, 마리오님, 까르코비츠님, 키노영감님). 웃음·의성어 반복도 붙인다(`롱롱롱롱`, `크핫핫핫핫`).
- 용어 대응: `セーブ` → 저장(`セーブブロック` → 저장블록), `はい/いいえ` → `예/아니요`, `BP` → `SP`(DS 표기).

### 2.4 줄바꿈 (DS 관찰 → 3DX 적용)
- DS 한 줄은 대부분 7~16자(최대 22자)이고, 한 페이지는 1~3줄이다. 3DX 폭 한도는 AGENTS.md 4.2를 따른다(필드 18자 권장, 21자 금지, 3줄 이하).
- 어절 경계에서만 끊는다. 감탄·호격, 주어, 서술 같은 의미 덩어리 단위로 나눈다: `만나서 반가워!\n난 옐로스타야!`(DS218#11), `비슷한 병을 여러모로\n조사해 봤는데…`(DS218#16).
- `[Next]` 페이지 수는 JP 그대로 둔다. DS가 페이지를 합치거나 나눈 곳도 3DX 페이지 경계에 맞춰 다시 나눈다. 줄 끝에 공백을 남기지 않는다.

## 3. 캐릭터별 말투 (본편, DS 근거)

### 3.1 쿠파 (クッパ)
- **등급:** 누구에게나 **반말(해라체)**로 거만하게 단정하고 명령한다.
  - 기본 어미: `~다!!` `~냐!?` `~거냐!?` `~겠다!!` `~테다!!` `~거다!!`
  - `~주마`: `つきあってやるぞ` → `같이 가 주마`(DS02D#37)
  - 예스러운 `~느냐`: `だれか ワガハイの 名前を 呼んだか！？` → `누가 이 몸의 이름을 불렀느냐!!`(DS218#42)
  - 명령: `~라!`, `당장 ~지 못해!!`(DS20A#6)
  - 당황하거나 혼잣말할 때는 해체 `~야/~어`: `어떻게 된 거야!! 화염이 나오질 않아!!`(DS20A#1)
- **1인칭:** `ワガハイ` → **이 몸**(`이 몸의 몸속이라고~!!!` DS1FB#5). 어색하면 `내`(`내 몸에 무슨 일이…` DS050#0). 자기를 높일 때는 `この クッパ様は 無敵だぞ` → `이 쿠파님은 무적이시다!!`(DS02D#22).
- **2인칭:** `オマエ` → 네놈/네 녀석/너, `オマエ達` → 너희들, `オマエら` → 이놈들(DS08B#18), `キサマ～！！` → `네 이놈~!!`(DS02D#13).
- **기타 대응:** `〜のだ` → `~것이다`(`次こそ マリオを やっつけるのだ！` → `다음엔 반드시 마리오를 물리칠 것이다!` DS23E#25). `はやく/さっさと` → `당장`.
- **웃음:** `ガハハハハ！` → **`크핫핫핫핫!`**(핫 3~4개). 비명·신음은 2.6 참고.
- **예문:**
  - o_gepu_01#6 `コラーーー！！ オマエは 何者だ！！！ / ワガハイの 体の中で なにをしているんだ！！` ↔ DS1FB#6 `어이!!! 네놈의 정체가 뭐냐? / 이 몸의 몸속에서 무슨 짓이냐!?`
  - o_koopa_end_01#2 `オマエ達 まだいたのか！ はやく 出ていけ！` ↔ DS23E#21 `너희들 아직도 있었느냐? 당장 나가라!`
  - o_peach_op_04#14 `…そうだろ！！ どうなんだ！？ キノじい！！` ↔ DS218#46 `안 그런가!? 맞을 텐데! 키노영감!! 어떻게 생각하나!?`
  - o_town_34_suishou_01_U#10 `おい！ マリオ！ 緑のヒゲ！ はやいもの勝ちだぞ！` ↔ DS13E#41 `어이! 마리오! 초록색 수염! 먼저 찾는 자가 임자다!`

### 3.2 까르코비츠 (ゲラコビッツ)
- **등급:** 반말. 문장 끝 `〜るる` → **`~롱롱`**. る 개수만큼 롱을 늘린다(`るる` → `롱롱`, `るるる` → `롱롱롱`, 드물게 `롱` 하나).
  - 평서 `~지롱롱`(가장 흔함)
  - 명령 `~라롱롱`·`~거라롱롱롱`
  - 의문 `~냐롱롱`(DS20E#5)
  - 그 밖에 `~어롱롱`(`또 늦었어롱롱!` DS0ED#3), `~든가롱롱`
- **웃음:** `ふるるるるる！！`·`るるるるる！！` → **`롱롱롱롱롱롱!!`**. 흥얼거림 `るるる～♪` → `롱롱롱~♪`(DS0EB#5).
- **빈사 상태(최종전 뒤):** `〜リュリュ`·`フリュリュリュ…` → **`~로로`**·`로로로로로…`. 예: o_areanone_lastboss_03_L#11 `わかったリュリュ… あきらめリュリュ…` ↔ DS281#15 `알았다로로… 포기하지로로…`
- **1인칭과 호칭:** `ワレ` → 나/내(`ワレの時代` → `나의 시대` DS05E#2). 쿠파는 쿠파 또는 너·네(더듬을 때 `니`). 자칭 `ゲラコビッツ様` → 까르코비츠님. 사회자를 맡을 때도 롱롱을 유지한다(`みんな～！ ノッてるるるる～～？` → `여러분~! 즐겁지롱롱롱~~?` DS02D#0).
- **예문:**
  - i_koopa_13_beam_01_L#4 `ピーチ姫を オマエに吸い込ませて キノコ王国は ワレのものになったるる…` ↔ DS051#4 `네게 피치공주를 빨아들이게 한 결과, 버섯 왕국은 나의 것이 되었지롱롱…`
  - i_koopa_13_escape_01_L#0 `オ オマエの中にいた ピーチ姫は ワ ワレが もらっていくるる！！` ↔ DS05E#0 `니, 니 몸속에 있던 피치공주는 내, 내가 저, 접수할 거지롱롱!`
  - o_peach_op_04#26 `おいっ！ メタボス！！ / こいつを 頼んだるるよ！` ↔ DS218#67 `어이! 메타보스!! / 이놈을 처리해라롱롱!`

### 3.3 메타보스 (メタボス)
- **말투:** JP는 가타카나로 끊어 말한다. DS는 **평범한 한글 해라체 단문**으로 옮기고, 조사를 빼서 어눌함만 살렸다. 가타카나를 흉내 내려고 띄어쓰기나 표기를 바꾸지 않는다.
  - 예: o_koopa_09_2_gerashow_01_U#24 `オマエ クルコト ワカッテ イタ！！ / キョウハ ココデ オレ ト タタカウ！ / ソシテ オマエ マケル！！` ↔ DS02D#15 `네놈 오는 거 알고 있었다!! / 오늘 여기에서 나와 싸운다! / 그리고 네놈 진다!!`
- **1인칭과 호칭:** `オレ` → 나. 쿠파는 쿠파/네놈. 까르코비츠에게는 하십시오체를 쓴다: o_peach_op_04#28 `カシコマリマシタ… ゲラコビッツ サマ…` ↔ DS218#68 `잘 알겠습니다… 까르코비츠님…`
- **웃음:** `ブハハハハハ！` → `무하하하하하!`(DS06E#0).
- **예문:** o_koopa_r_31#11 `クッパ！ コンドハ サッキノ ヨウニハ イカナイゾ！！` ↔ DS06E#1 `쿠파! 이번엔 아까처럼 되진 않을 것이다!!`

### 3.4 옐로스타 (イエロースター, 스타의 정령)
- **이름:** `イエロースター` → 옐로스타(DS218#11), 종족 `スターの精` → 스타의 정령. 쿠파만 `チッピー` → **치피**라고 부른다(DS223#3·13).
- **등급:** 피치공주·키노영감·쿠파를 포함해 누구에게나 **반말**을 쓴다. 밝고 당찬 해체다.
  - 어미: `~야` `~어` `~지?` `~잖아!` `~는데?` `~라고!` `~나 봐` `~자!`
  - JP 여성어미(`〜わ/〜わよ/〜のよ/〜ちょうだい`)는 따로 흉내 내지 않고 반말로 녹인다.
  - `〜しましょう` → `~해 보자`/`~해 봐!`(i_air_01#2 ↔ DS181#2, i_energy_22#2 ↔ DS0E5#7)
- **1인칭·2인칭:** `私` → 나/난, `あなた` → 너/네(쿠파에게도), `あなた達` → 너희들. 쿠파와 처음 마주칠 때 `당신`을 쓴 예가 하나 있다(DS218#48, 화자 추정).
- **감탄:** `ごめんなさ～い！！！` → `늦어서 미아~안!!!`, `じゃあね！！！` → `안녕!!!`(DS20A#9), `はあ～い！！` → `안녕~!!`(DS23E#7), `ふう…` → `휴우…`
- 메뉴·튜토리얼 설명도 옐로스타 목소리로 쓴다(`~할 수 있어.` MData__mfset_MenuMes).
- **예문:**
  - o_peach_op_04#5 `なにも できなくて わるかったわね！ / スターの精だって できないことも あるわよ！ / あきらめてちょうだい！` ↔ DS218#27 `아무것도 못 해 줘서 미안하게 됐어! / 스타의 정령이라도 불가능한 건 있다고! / 포기해 주면 고맙겠어!`
  - o_gepu_03#7 `だから 知らないわよ！ / あなたが ほのおをはけなくなって 私に なんの得があるの？` ↔ DS20A#7 `모르는 일이라고 하잖아! / 네가 화염을 못 써서 나한테 무슨 이득이 있겠어!`
  - o_koopa_39#10 `うふふ。どうせ 泣いてばっかり だったんでしょ？` ↔ DS28F#12 `우후훗. 무섭다고 질질 짰던 거 아니야?`

### 3.5 다크스타 / 다크쿠파
- **다크스타(ダークスター):** JP 가타카나의 끊긴 말을 해라체 단문으로 옮기고, 구 사이를 `…`로 끊는다.
  - o_peach_1f_03#19 `オマエノ カラダ コピー シタ… オマエノ チカラモ コピー シタ…` ↔ DS20F#13 `네놈의 몸을 복사했다… 네놈의 힘도 복사했다…`
  - #20 `タリナイ… / パワーガ タリナイ…` ↔ DS20F#15 `부족하다… / 파워가… 부족하다…`
  - #27 `チガウ…` ↔ DS20F#23 `아니군…`
- **다크쿠파(ダーククッパ → 다크쿠파):** 차갑고 짧은 해라체로 말하고, 쿠파를 너/네놈이라고 부른다. 쿠파식 허세(`~주마`, `크핫핫`)는 쓰지 않는다.
  - o_peach_t_02#0 `オマエの能力は すべてコピーした。 オマエに もう 用はない。` ↔ DS237#1 `너의 능력은 이미 복사했다. 더 이상 네놈에게 볼일은 없다.`

### 3.6 쿠파 부하 (쿠파 군단)
- **종 이름(DS):**
  - 종족: クリボー 굼바, ノコノコ 엉금엉금, カメック 마귀, ヘイホー 헤이호, ボムへい 폭탄병, テレサ 부끄부끄, パタパタ 펄럭펄럭, チョロプー 쪼르뚜
  - 집단: クッパ軍団 쿠파 군단, ○○軍団 ○○ 군단, ボコスカ○○ ○○부대, 手下 부하
  - 트리오: クリッキー 굼비, ヘイファー 헤이포, パタボン 펄러크
- **쿠파에게:** **쿠파님**과 **하십시오체**를 예외 없이 쓰고, 쿠파의 행동에는 `-시-`를 붙인다(`빨리 쿠파님 안 오시나~` DS06D#5).
  - 1인칭: `我々/我ら/ボクら/オレ達` → 쿠파 앞에서는 `저희(들)`, 동료끼리는 `우리`. 굼비의 `オレ` → 저.
  - 애원·설명·질문에는 해요체가 섞이고 말끝에 `~`를 붙인다(`쿠파님~ 기분은 어떠신가요~?` DS23E#18).
- **말버릇은 평탄화, 리듬은 살림:** JP의 캐릭터 어미(`であります`, `ですぞ`, `ッス`, 무사풍 고어)는 **표준 존댓말로 평탄화**한다.
  - o_chika_09_before#16 `…任命されたであります！` ↔ DS0DA#10 `저희 쪼르뚜 형제들이 임명되었습니다!`
  - 마귀: o_peach_2f_04#29 `こちらです！ 我らは こちらですぞ！！` ↔ DS1A3#11 `이쪽입니다! 저희 여기에 있어요!!`
  - 대신 늘임·더듬기·메아리 같은 리듬은 살린다. 구호 `クッ パッ さまっ！！` → `쿠 파 님!!`(DS0F9#7)
- **동료끼리와 마리오에게:** 동료끼리는 반말·명령형(`다들! 각오는 됐겠지!?`, `첫 주자 나와라~!!` BAI__BMes_cf:0), 마리오에게는 적대하는 반말을 쓴다.
- **대상에 따라 높임을 가린다:** o_koopa_24#12 `クッパ様 キターー！！！` ↔ DS094#5 `쿠파님 오셨다――!!!` / #9 `マリオ キターーー！！` ↔ DS094#17 `마리오가 왔다―――!!`
- **배신과 매수:** 배신(트리오)이나 매수(쪼르뚜) 뒤에는 쿠파에게 반말이나 `당신`을 쓴다. 예: o_koopa_18#19 `もう オマエの時代は… 終わった！` ↔ DS089#45 `이제 너의 시대는… 끝났어!`
- **까르코비츠 측:** `ゲラコビッツ様` → **까르코비츠님**(서술도 높임: `진행하는 중이십니다`), `メタボス様` → 메타보스님(`大変です メタボス様！` → `큰일입니다, 메타보스님!` DS070#13), `テレサーズ` → 부끄부끄 요원.
- **감탄:** `ぐわ～` → 으으~~~, `イタタタ` → 아야야야야, `助けて～` → 살려 줘~, `ひぇ～` → 꺄아~~~~, `りょうかい！！` → 옙!!, `ラジャー` → 라저―!!, `そりゃー` → 흐아―――압!!!!!
- **예문:**
  - b_sys#274 `クッパ様！ 我らクリボー軍団も 共に戦います！` ↔ BAI__BMes_cf:0#1 `저희 굼바 군단도 함께 싸우겠습니다!`
  - o_zutsuda_15#4 `ク クッパ様～！！ ご無事でしたか～！！` ↔ DS108#6 `쿠, 쿠파님~!! 무사하셨습니까~!!`
  - o_koopa_end_01#1 `…ボクらには クッパ様だけです～` ↔ DS23E#20 `…저희에겐 쿠파님밖에 없습니다~`
  - o_zutsuda_04_after#15 `見世物じゃ ないぞ！ あっち 行け！` ↔ DS0F9#14 `뭐 구경 났어? 당장 가 버려!`

### 3.7 까르코비츠 홀의 세뇌 부하·기타 조연
- **안내원 메아리 개그:** 끝의 서술 덩어리를 반복한다. o_koopa_07#6·7 `おすわりくださ～い。`/`さ～い。` ↔ DS02B#20·21 `빈자리에 앉아 주세요~`/`주세요~`
- **커플:** `ダーリン` → `달링♥`, `ハニー` → `허니~`, `ああ～ん` → `아잉~ 몰라몰라~♥`(DS025). ♥는 DS가 덧붙였다.
- **부끄부끄 요원:** 손님 접대 말투(해요체/하십시오체)를 쓰고, `ケケケケ` → `케케케케!`로 웃는다. 예: gerashow#7 `…お勝ちになった クッパ様ですね～` ↔ DS02D#33 `이분이 우승하신 쿠파님이시군요~`
- **펄럭펄럭 3형제:** 두목은 건달 반말(`クックック` → `큭큭큭…`)을 쓰고, 부하는 두목을 `アニキ` → `형님`이라 부르며 해요체를 쓴다. 예: o_peach_g_04#8 `アニキ！ いっきに…要求しちゃいましょうよ！` ↔ DS1AA#24 `형님! …다시 300코인을 불러 봐요!`
- **와르르(カロン, 추정):** 가타카나 어미를 반말로 바꾸고, 쿠파를 `아저씨`라고 부른다. 예: o_koopa_01#12 `…だっっっっセ～～！！` ↔ DS025#27 `촌~~~~~~스럽긴!!`

### 3.8 블록 상점 신사 (ブロック・ムッシュ)와 블도그
- **이름:** 본명은 JP·DS 대사 어디에도 나오지 않는다(라벨은 brilock). 대사에서 이름을 부르지 않는다. 표기는 5번 참고.
- **호칭:** 자칭 `ミー` → **미**, 상대(쿠파, 전투 중에는 마리오도) `ムッシュ～` → **신사~**, `マリオさん` → 마리오님, `ブロドッグちゃん` → (우리) 블도그, `ブロキャットちゃん` → (귀여운) 블캐츠.
- **말투:** 해요체·하십시오체에 **영어 음차**를 섞는다. JP의 프랑스어는 DS에서 영어로 바꿨다: `ボンジュール` → 하이~, `メルシー` → 땡큐 (베리 머치), `シルブプレ` → 플리즈, `コマンタレブ` → 하우 아 유. 영어 말장난(`ゴキゲンが ストレートじゃない`)은 뜻만 옮긴다 → `기분이 베리 배드`(DS035#11).
- **예문:**
  - o_koopa_r_33#8 `ボンジュ～ル ムッシュ～ まいど ご利用 メルシ～ね。` ↔ DS145#7 `하이~ 신사~ 항상 이용해 줘서 땡큐 베리 머치~`
  - o_ekubon_02_after#0 `ウェーーイト！ お待ちください！！` ↔ DS28D#5 `웨이~~~트! 잠깐만요!!`
  - o_mushiba_12#5 `オウ マイ ドッグ！ ワッツ ハップ～～～ン！？` ↔ DS035#7 `오우! 마이 도그! 왓 해프~~~은!?`
- **블도그:** `ガルルルルル…` → `으르렁… 으르렁…`(DS28D#0). 블캐츠는 대사가 없다.

### 3.9 피치공주 (ピーチ姫)
- **1인칭:** `わたくし/私` → **저**. 예: i_metaboru_16#6 `わたくししか いないからです！` ↔ DS042#14 `저밖에 없기 때문이에요!`
- **등급:** 누구에게나 **해요체**를 쓴다. JP 반말(`〜のね`, `ありがとう`, `〜ちょうだい`)도 해요체로 올린다.
  - o_peach_op_04#7 `２人とも… 落ちついてちょうだい。` ↔ DS218#29 `두 분 모두… 진정하세요.`
  - i_metaboru_15#16 `…助けてくれたのね！ ありがとう！！` ↔ DS04F#5 `…절 도와주셨군요! 고마워요!!`
- **호칭:**
  - 마리오·루이지는 이름만 부른다(`마리오! 루이지! 고마워요!!!` DS04F#11).
  - `あなた` → 당신(옐로스타에게: `또 당신의 도움을 받았네요. 고마워요.` DS218#57, `옐로스타!! 당신도 함께였군요!` DS04E#5).
  - 적은 `저 까르코비츠라는 자`(DS042#10)라고 부른다.
  - 쿠파에게도 해요체를 쓴다(`이곳엔 대체 무슨 일이죠!?` DS218#45, 화자 추정).
- **감탄:** `まあ` → 어머!/어쩜, `え？` → 네?, `ええ` → 네, `キャーーッ` → 꺄아――앗!!!, `そうですわ` → 맞아요, `ごめんなさい` → 죄송해요
- 옛이야기를 들려줄 때는 `~되었어요…`, `~답니다…`로 끝맺는다(DS095).

### 3.10 키노영감 (キノじい)
- **이름:** 키노피오는 `키노영감님`, 옐로스타·쿠파·피치는 `키노영감`이라고 부른다. 자칭 `じい` → **할아범**/`이 영감`, 3인칭 `キノじい` → 키노영감, `わしら` → 우리.
- **등급:** **하십시오체 중심**이고, 질문·권유에는 해요체(`~할까요?`, `~들으실래요?`, `~세요`)를 쓴다.
  - `〜ですぞ/〜ますぞ/〜ですな` → `~입니다/~습니다/~군요`
  - `〜くだされ/〜なされ` → `~주십시오/~세요`
  - `〜ですじゃ` → `~단 말입니까`
  - 한자어·관용구를 즐겨 쓴다(`조속히 원인을 규명하여` DS218#1, `걱정 붙들어 매십시오` DS281#39).
- **호칭:** `マリオどの` → **마리오님**(흔히 `마리오님, 그리고 루이지님`), `マリオどの達` → 두 분, `姫様` → **공주님**, `キノックルどの` → 키노클님
- **감탄:** `おお` → 오오, `おや` → 어라, `なんと` → 뭐라고요, `むむむ` → 흐으음, `ムッ！` → 윽!, `いやはや` → 아니 뭐, `さてさて` → 에헴, `ひゃ～～` → 흐엑~~
- **예문:**
  - i_pump_16#13 `ああ～ 姫様… なんと おいたわしい… / クッパなんぞの 体の中に おひとりで…` ↔ DS00D#5 `아아~ 공주님… 가엾은 우리 공주님… / 쿠파 따위의 몸속에 홀로…`
  - i_pump_16#19 `…なんとしてでも 姫様を 助け出してくだされ！` ↔ DS00D#22 `…무슨 짓을 해서든 공주님을 반드시 구해 주십시오!`
  - 말더듬 개그는 2.5 참고.

### 3.11 오키노 선생 (Dr.コキノ)과 병원
- **이름:** 키노피오·조수는 **오키노 선생님**, 옐로스타는 오키노 선생이라고 부른다. 간판이나 첫 소개에서는 **닥터 오키노**다(`Dr.コキノの 助手ですよ。` → `닥터 오키노의 조수예요.` DS218#21). `ミラクルコキノワクチン` → 미라클 오키노 백신.
- **`〜でしょう` 말버릇:** DS는 이 말버릇을 살리지 않고 하십시오체와 `~지요/~군요`로 옮겼다.
  - o_town_34#26 `できたでしょう！ できたでしょう！` ↔ DS0F4#5 `완성입니다! 완성입니다!`
  - `まあ 待つでしょう。` → `잠깐 기다리시지요.`(DS0F4#11)
  - 점을 치는(트랜스) 대사만 `~ㄹ 거다`를 반복한다(`아~~ 보인다. 보일 거다.` DS13E#6).
- **호칭:** `あなた達` → 당신들, `２人` → 두 분, 자칭 `私` → 저
- **웃음:** `ふっふっふっふ` → 훗훗훗훗, `うほほほ… ほーほほほ…` → 우호호호… 호―호호호…, `お静かに` → 조용!/쉿!
- **조수(여성):** 해요체(`…전 이만 실례하겠어요.` DS218#25)
- **오키오키(コッキー):** 반말로 같은 말을 되풀이한다(`けってい けってい～！！` → `결정! 결정~!!` DS0F2#55).

### 3.12 키노피오 (キノピオ)
- **등급:** 마리오 형제에게 **해요체**를 쓴다. 안내·보고에는 하십시오체가 섞이고(`…입구입니다.` DS0EF#0), 혼잣말은 반말이다. 여성 키노피오의 JP 반말(`〜のよ/〜ね`)도 해요체로 올린다: `メタコロ病が 治ったのよ！！` → `뚱뚱데굴병이 나았어요!!`(o_town_20#19 ↔ DS0CC#21)
- **호칭:** `マリオさん/マリオ様` → **마리오님**, `お２人` → 두 분, `お客様` → 손님, `キノじい` → 키노영감님, `ピーチ姫` → **피치공주님**, `コキノ先生` → 오키노 선생님. 1인칭 `ボク` → 저, `ボクら` → 저희들/우리.
- **쿠파 앞:** 비명만 지른다. `ク クッパだ～～！！！` → `쿠, 쿠파다~~!!!`(DS0EF#5)
- **감탄:** `うわ～` → 우와~, `え？` → 네?, `あら` → 어머, `あらららら` → 어머머머, `そうそう` → 아, 맞다!, `いらっしゃいませ` → 어서 오세요(고급 숍은 어서 오십시오)
- **특수 말투:** 시골 말투 환자나 ざます 부인처럼 특이한 말투도 DS는 **표준 해요체로 평탄화**했다(DS0F2#3, DS128#11).
- **가족:** 아이가 엄마에게는 해요체, 엄마가 아이에게는 해라체(`왔니?`, `…될 수 없단다.` DS09C)
- **예문:**
  - o_peach_op_01#1 `会議ですよ！ 会議！！ 急いでください！` ↔ DS21A#1 `회의예요! 회의!! 어서 서둘러 주세요!`
  - #2 `…あ。ルイージさんが くるのも ね。` ↔ DS21A#2 `…아, 루이지님이 오는 것도요.`
  - o_town_41#8 `お待ちしておりました。マリオ様に ルイージ様ですね。` ↔ DS0F1#1 `어서 오십시오. 마리오님, 루이지님.`

### 3.13 헬로글로빈 일족 (ヘモグロびん)
- **이름:** 헬로글로빈, 리프트로빈(リフトロびん), 토템헬로글로빈, 찡글로빈(ワルグロびん), 헬로글로인(ヘモグロじん)
- **규칙:** **반말로 문장을 끝낸 뒤 `로빈`을 붙여 쓴다.** 문장부호는 로빈 뒤에 둔다. DS에서 가장 많은 형태는 `~거야로빈`(67회)이다. 1인칭 `私` → 나/난, `我ら` → 우리.

| 종류 | JP → KO |
|---|---|
| 평서 | `めずらしいびん` → `별일이네로빈`, `教えちゃうびんよ` → `알려 줄게로빈`(DS1FE#0) |
| 명령·권유 | `叩いてみるびん` → `두드려 봐로빈`, `必ず２人で乗るびんよ！` → `반드시 2명이 타야 해로빈!`(DS1F1#5) |
| 질문 | `わかったびんか？` → `이해했어로빈?`(DS1F2#5), `聞いておくびん？` → `들을래로빈?`(DS1F1#7) |
| 명사·감탄 | `成功び～～ん！` → `성공로빈~~!`, `失敗びん！` → `실패야로빈!`(DS1F2) |
| 이름째 붙임 | `…に弱いヘモグロびん！` → `…에 약해헬로글로빈!`(DS009#0) |
| 늘임 | `おしえな～いび～ん！！` → `안 가르쳐 주~지로빈!!`(로빈 자체는 늘이지 않음, DS1FE#2) |

- **선택지:** 플레이어의 말이므로 말버릇 없이 `예/아니요`로 쓴다. 단, JP 선택지에 `的な`가 붙어 있으면 `아마 예/아마 아니요`.
- **저장 헬로글로빈:** `〜的な`를 문장 앞의 `아마`로 옮긴다(`知りたい的な？` → `아마 궁금하지?` DS1FE#1).
- **헬로글로인:** 말버릇 없이 엄숙하게 말한다(`우리는 헬로글로인…`, `구해 주길 바란다…`, `건너 주십시오…` DS077).

### 3.14 차크란과 경상도 사투리
- **화자:** 3DX 대사에서 간사이벤을 쓰는 화자는 **차크란(チャクラン) 계열뿐**이다. DS는 이들을 모두 **경상도 사투리 반말**로 옮겼다.
  - 현인 본인: o_mushiba_24 ↔ DS170
  - 하늘의 목소리: o_gepu_08 ↔ DS163
  - 워프 안내: o_gepu_02 ↔ DS209, o_areanone_allmap_01_U ↔ DS283
  - 엔딩 랭크 평가(추정): o_areanone_end_02_U ↔ DS29F
- **호칭:** 자칭 `このチャクラン様` → `이 차크란님`, `ワシ` → 내/내는, `あんた` → 니, `あんたら` → 느그들. 쿠파는 `거기 있는 큰 녀석~`이라고 부른다. 옐로스타는 차크란을 `차크란씨`라고 부른다. 선택지는 표준어로 쓴다.

### 3.16 내레이션·시스템
- **내레이션:** 해라체로 서술한다.

- **3DX 신규 안내 제안:**
  - JP `〜されました。` → `~되었습니다.` 예: `フィールドガイドに 項目が追加されました。` → `필드 가이드에 항목이 추가되었습니다.`
  - 공통 힌트 `HPとBPの回復も 忘れないようにしましょう。` → `HP와 SP 회복도 잊지 마세요.` DS에는 `~합시다`가 한 번도 없으므로 쓰지 않는다.

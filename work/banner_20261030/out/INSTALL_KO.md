# HOME 메뉴 한글 배너 설치 방법 (New 3DS · Luma3DS)

이 파일을 설치하면 HOME 메뉴에서 게임을 골랐을 때 위 화면에 나오는 3D 배너의 로고가
「마리오&루이지 RPG3 DX 디럭스」 한글 로고로 바뀝니다.
게임 내용, 세이브, v1.2 업데이트, SD 카드의 한글 패치(`luma/titles/00040000001CA900/`)는 바뀌지 않습니다.
HOME 메뉴 아이콘 밑의 게임 이름 글자는 그대로입니다.

- 설치 파일: `00040000001CA900_ML3DX_KoreanBanner.cia` (약 700MB)
- 확인값(SHA-256): `7e70eaee4d262f7669aeb03d4c4b217edfd7f79ee1e2edd0c301e92d0ae00f2d`

## 준비

1. 게임이 **SD 카드에 설치된 버전**인지 확인합니다.
   FBI → `Titles` 목록에 `00040000001CA900`(マリオ&ルイージRPG3 DX)이 있으면 됩니다.
   게임 카드로 하는 경우에는 이 방법을 쓰지 마세요. 게임 카드의 배너는 바꿀 수 없고,
   설치하면 세이브가 따로인 게임이 하나 더 생깁니다.
2. (권장) 세이브를 백업합니다. Checkpoint가 있으면 게임을 고르고 `Backup`을 누릅니다.
3. SD 카드 빈 공간이 **1.5GB 이상**인지 확인합니다(설치 파일 0.7GB + 설치 중 임시 공간).
4. 배터리를 충분히 충전하거나 충전기를 꽂아 둡니다.

## 설치

1. 3DS 전원을 끄고 SD 카드를 PC에 연결합니다.
2. `00040000001CA900_ML3DX_KoreanBanner.cia`를 SD 카드의 `cias` 폴더에 복사합니다(폴더가 없으면 만듭니다).
3. SD 카드를 3DS에 다시 넣고 평소처럼 켭니다(Luma3DS).
4. FBI를 실행합니다 → `SD` → `cias` → `00040000001CA900_ML3DX_KoreanBanner.cia`를 고릅니다
   → `Install CIA` → A 버튼으로 확인합니다.
5. 설치가 끝날 때까지 기다립니다(몇 분 걸립니다). 끝나면 B 버튼으로 나와 HOME 버튼으로 FBI를 닫습니다.
6. 3DS를 한 번 다시 켭니다.
7. HOME 메뉴에서 게임 아이콘을 고르면 위 화면 배너에 한글 로고가 보입니다.

## 하지 말아야 할 것

- FBI `Titles`에서 게임을 **먼저 지우지 마세요**. 게임을 지우면 세이브도 함께 지워집니다.
  지우지 않고 그 위에 그대로 설치하면 세이브는 남습니다.
- v1.2 업데이트(`0004000E001CA900`)는 다시 설치하거나 지울 필요가 없습니다. 그대로 둡니다.
- SD 카드의 `luma/titles/00040000001CA900/` 한글 패치 폴더는 그대로 둡니다.

## 되돌리기

원래 CIA(`00040000001CA900.00000002 … (J).standard.cia`)를 같은 방법(FBI → `Install CIA`)으로 설치하면
일본어 배너로 돌아갑니다. 이때도 게임을 먼저 지우지 않습니다.

## 참고

- 이 CIA는 원래 CIA와 같은 방식(복호화된 CIA)이라 Luma3DS가 켜진 3DS에서만 설치됩니다.
  원래 CIA를 설치할 수 있었던 기기라면 똑같이 설치됩니다.
- CIA 안의 티켓은 원래 CIA와 같습니다. 게임을 eShop에서 산 기기라면 설치할 때 기기의 티켓이
  이 CIA의 티켓으로 바뀝니다(Luma3DS에서는 그대로 실행됩니다).
- Azahar에는 HOME 메뉴 배너가 없어서 에뮬레이터에서는 이 변경을 볼 수 없습니다. 실기에서만 보입니다.
- 설치 중 오류가 나면 위 「되돌리기」처럼 원래 CIA를 설치하고 알려 주세요.

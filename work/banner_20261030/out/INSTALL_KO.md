# HOME 메뉴 한글 배너·게임 이름 설치 방법 (3DS · Luma3DS)

이 파일을 설치하면 HOME 메뉴에서 두 가지가 한글로 바뀝니다.

- 게임을 골랐을 때 위 화면에 나오는 3D 배너의 로고: 「마리오&루이지 RPG3 DX 디럭스」 한글 로고
- 게임 이름: 「마리오&루이지 RPG3 DX」 (**한국어 본체에서만** 보입니다. 다른 지역 본체는 시스템 글꼴에 한글이 없어서 원래대로 나옵니다)

게임 내용, 세이브, SD 카드의 한글 패치(`luma/titles/00040000001CA900/`)는 바뀌지 않습니다.
한글 대사와 60fps는 지금처럼 SD 카드의 한글 패치가 맡습니다.

| 파일 | 크기 | 무엇 | SHA-256 |
|---|---|---|---|
| `00040000001CA900_ML3DX_KoreanBanner_Name.cia` | 약 700MB | 본편: 한글 배너 + 한글 이름 | `c25d7dc735874d7ba4add56e6bde5949adc8b8f265e05871a70622045a741bd1` |
| `0004000E001CA900_ML3DX_v1.2_KoreanName.cia` | 약 29MB | 업데이트 Ver. 1.2: 한글 이름 (내용은 공식 Ver. 1.2 그대로) | `a2a0047d37c185956f3d26c5baaa5a1d7ed00e23f894a0111b48908fa15f1db5` |

두 파일을 **모두** 설치하세요. 본편과 업데이트에 같은 이름 정보가 들어 있는데, HOME 메뉴가 어느 쪽 이름을 쓰는지는 아직 실기에서 확인하지 못했습니다. 둘 다 바꿔 두면 어느 쪽이든 한글로 나옵니다.

예전에 만든 `00040000001CA900_ML3DX_KoreanBanner.cia`(배너만 바꾼 것)는 이 파일로 대신합니다.

## 준비

1. 게임이 **SD 카드에 설치된 버전**인지 확인합니다.
   FBI → `Titles` 목록에 `00040000001CA900`(マリオ&ルイージRPG3 DX)이 있으면 됩니다.
   게임 카드로 하는 경우에는 이 방법을 쓰지 마세요. 게임 카드의 배너와 이름은 바꿀 수 없고,
   설치하면 세이브가 따로인 게임이 하나 더 생깁니다.
2. 업데이트 Ver. 1.2(`0004000E001CA900`)가 설치돼 있는지 확인합니다. 한글 패치에 꼭 필요합니다.
3. (권장) 세이브를 백업합니다. Checkpoint가 있으면 게임을 고르고 `Backup`을 누릅니다.
4. SD 카드 빈 공간이 **1.5GB 이상**인지 확인합니다(설치 파일 0.73GB + 설치 중 임시 공간).
5. 배터리를 충분히 충전하거나 충전기를 꽂아 둡니다.

## 설치

1. 3DS 전원을 끄고 SD 카드를 PC에 연결합니다.
2. 위의 CIA 두 개를 SD 카드의 `cias` 폴더에 복사합니다(폴더가 없으면 만듭니다).
3. SD 카드를 3DS에 다시 넣고 평소처럼 켭니다(Luma3DS).
4. FBI를 실행합니다 → `SD` → `cias` → `00040000001CA900_ML3DX_KoreanBanner_Name.cia`를 고릅니다
   → `Install CIA` → A 버튼으로 확인합니다. 끝날 때까지 기다립니다(몇 분 걸립니다).
5. 같은 방법으로 `0004000E001CA900_ML3DX_v1.2_KoreanName.cia`도 설치합니다.
6. B 버튼으로 나와 HOME 버튼으로 FBI를 닫고, 3DS를 한 번 다시 켭니다.
7. HOME 메뉴에서 게임 아이콘을 고르면 위 화면 배너에 한글 로고가, 이름에 「마리오&루이지 RPG3 DX」가 보입니다.
8. 게임을 켜서 타이틀 화면 오른쪽 아래가 「Ver. 1.2」이고 한글로 나오는지 확인합니다.

## 하지 말아야 할 것

- FBI `Titles`에서 게임이나 업데이트를 **먼저 지우지 마세요**. 게임을 지우면 세이브도 함께 지워집니다.
  지우지 않고 그 위에 그대로 설치하면 세이브는 남습니다.
- SD 카드의 `luma/titles/00040000001CA900/` 한글 패치 폴더는 그대로 둡니다.

## 이름이나 배너가 그대로일 때

- 3DS를 한 번 더 껐다 켜 봅니다.
- 본체 언어가 한국어인지 확인합니다. 한글 이름은 한국어 본체에서만 나옵니다.
- 그래도 이름만 그대로라면 두 파일 중 하나가 빠졌는지 FBI `Titles`에서 확인하고 알려 주세요.

## 되돌리기

원래 CIA(`00040000001CA900.00000002 … (J).standard.cia`, `0004000E001CA900.00000001 … (J).standard.cia`)를
같은 방법(FBI → `Install CIA`)으로 설치하면 일본어 배너와 원래 이름으로 돌아갑니다. 이때도 게임을 먼저 지우지 않습니다.

## 참고

- 두 CIA는 원래 CIA와 같은 방식(복호화된 CIA)이라 Luma3DS가 켜진 3DS에서만 설치됩니다.
  원래 CIA를 설치할 수 있었던 기기라면 똑같이 설치됩니다.
- 바뀐 것은 배너·이름 정보와 그 해시뿐입니다. 게임 코드, 데이터, 티켓, 인증서는 원래 CIA와 바이트까지 같습니다.
- CIA 안의 티켓은 원래 CIA와 같습니다. 게임을 eShop에서 산 기기라면 설치할 때 기기의 티켓이
  이 CIA의 티켓으로 바뀝니다(Luma3DS에서는 그대로 실행됩니다).
- Azahar에는 HOME 메뉴가 없어서 에뮬레이터에서는 이 변경을 볼 수 없습니다. 실기에서만 보입니다.
- 설치 중 오류가 나면 위 「되돌리기」처럼 원래 CIA를 설치하고 알려 주세요.

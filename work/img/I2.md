## 정한 것
- 큰 글자 판단: 비트맵은 자기 em의 1.25배까지(font 15px → 18.75, font_l 21px → 26). 그보다 크면 GothicA1을 목표 크기로 직접 렌더.
- 굵기 목표 = 일본어 채움 획. 틈(gap_min 1~1.5px)은 지킨다 → 빽빽한 음절은 0.75~0.9배(한계로 README에 적음).
- 은행 글자는 em 14px 이상 그림에서만(작은 그림 음절은 꾸밈을 벗기면 깨짐).

## 리드 확인
- ETC1A4 인코더(`libtex3ds.encode` = etcpak) 품질: 흰 글자 속 1px 검은 틈에서 회색 블록 흔적. 원본 일본어 재인코드 PSNR 34.6dB, 한국어 33.7dB. → 리드가 인코더를 고침(블록별 정밀 탐색, 52~99dB). README 7장 반영함.
- I6 `scripts/libhb_ko.py`의 v1.0용 덮어쓰기(`"*": {"source": "font"}`, `weight: 0.0`, `BIG_SOURCE`, `WEIGHT_FACTOR`)를 지우면 v1.1 기본값(굵기·크기 규칙)이 적용된다. 지우지 않아도 동작은 한다(API 호환).
- 「사용하기」(btn_USE), 「배지 숍」 등 낱말은 lyt_plan.json의 ko 그대로 씀.

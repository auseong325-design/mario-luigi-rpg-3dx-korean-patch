# I4 — 모델 텍스처 + 로고 진행 기록

## 1. BCH 도구·빌더 (완료)
- `scripts/libbch.py`: BCH(backward 0x22) 텍스처 표(사전 #3) → 항목 = 3×(명령 포인터, 워드 수) + u8 포맷 + u8 밉맵 수 + 이름.
  유닛0 PICA 명령 0x82(폭<<16|높이), 0x85(데이터 구역 기준 주소), 0x8E(포맷). 포인터는 구역 기준 상대값 → 파일 안에서 그대로 계산.
  **BCH 픽셀은 위 행부터 저장**(BFLIM과 반대) → `libtex3ds.decode/encode(..., flip=False)`.
  제자리 교체(길이·레이아웃 불변), 밉맵은 프리멀티 알파 2×2 평균으로 다시 만든다(밉맵 있는 텍스처는 `cs_01_fog` 1개뿐).
  자체 검사: 205모델·793텍스처 파싱, 무손실 303개 decode→encode 바이트 일치.
- `scripts/build_fmdl.py`: `extract`(3DX·1DX 전부 PNG + `work/img/fmdl_manifest.json` + `work/img/fmdl/sheets/`),
  `--identity`(OK, 16,018,524바이트 일치), `--selftest`, 기본 빌드(`work/img/fmdl_ko/<모델>/<텍스처>.png` → 같은 픽셀의 모든 복사본 교체 →
  `work/build/fmdl_stage/romfs/FMdl/JP/FMdl.dat`, 다시 읽어 비교).

## 3. 로고
- 1DX 한국판 로고 `mg_map_title_logo_KR_ko` = BCH(같은 버전). `ttl_c02_str_KR`(RGB565) + `ttl_c02_str_KR_a`(A8 알파) = 「마리오&루이지RPG1 DX 디럭스」.
- 3DX 꾸밈(측정): 테두리 남색 (0,51,85) 약 5px, 아래로 입체 두께(적갈색→남색), 바깥 흰 번짐 약 8~10px, 면은 위 주황→아래 빨강(マリオ)/연두→초록(ルイージ), 획 왼쪽·아래 안쪽에 흰 광택선.


### 3.1 타이틀 로고 방법 (work/img/logo/)
- `logo_lib.py`: 층 모델. F(글자 면) → B(남색 몸통 = F를 r_o 팽창 ∪ (sx,1) 방향으로 D줄 쓸어낸 입체를 r_e 팽창) → 번짐.
  원본에서 잰 값: bottom r_o=5, 입체 (0.75,1)×6~7줄, r_e 4.5~5 (몸통 IoU 0.91~0.98). 면색 = 행별 표(원본 면 픽셀 평균),
  광택 = P(흰 선 | 가장자리까지 거리, 바깥 법선 각도) 표(원본에서 측정: 거리 1.5~3px, 아래쪽 법선 30~150°),
  몸통 음영·번짐 = 원본 픽셀을 기하 특징(얼굴까지 거리, 몸통 가장자리 거리·법선, 입체 끝 사본 거리)으로 찾는 k-NN / 번짐 표.
  검증: 일본어 면 마스크로 다시 그려 원본과 나란히 비교(`fit/rerender_*.png`).
- `kr_skeleton.py`: 1DX 로고에서 마리오/루이지 면 마스크(1DX 새싹 장식은 뺌, &는 3DX 것을 씀).
- `make_bottom.py`: 1DX 배치(마리오&루이지)를 가로 0.703·세로 0.87(장평 81%)로 줄여 x 44~274에 배치, & 이동(+15px),
  RPG·오른쪽은 원본 픽셀(R 안에서 이음), 마리오·루이지 실루엣은 원본 모양 그대로 마·루의 둥근 머리 글자 위로 옮김.
- `make_pieces.py`: `title_logo_M_JP`/`L_JP`(128×64) 각각 따로 측정(r_o≈3, 입체 (0.75,1)×6).
- `make_top.py`: デラックス → 1DX 로고의 「디럭스」(같은 역할) 0.64×0.70, 자간 +3px, 남색 테두리 2.5px·흰 번짐은 원본에서 측정. DX·3·™는 원본.

- `make_pieces.py` 결과: M 0.69/0.70, L 0.65(장평 99~100%). 1DX의 큰 마·루 글자 때문에 JP 글자 상자 대신 텍스처 높이 전체(여백 2.5px)를 씀.
- `make_start.py`: ゲームスタート → 1DX `btn_GAMESTART_12_KR_ko`의 「게임 시작」(같은 낱말) 원래 크기(×1.00) + 획 0.5px 보강.
  노란 판은 행별 중앙값으로 복원, 테두리 2px·그림자 (1,1)px·색은 원본에서 측정(몸통 IoU 0.90).
- 파일 선택 로고(리드 추가 지시): `make_fileload_ml.py`(마리오&루이지 RPG3, DX 없음 — 타이틀과 같은 배치를 이 로고 크기로 옮김),
  `make_fileload_kj.py` + `kj_skeleton.py`(쿠파주니어 RPG). 좌우 조각(144+256)은 한 장으로 처리 후 나눔 → 경계 연속.
  PNG: `work/img/ko/lyt/MLyt/MENU_FILE_LOAD_JP_ja/LOAD_GAME_IMG_{ML,KJ}_{L,R}_00_JP_ja.png`.
  `build_lyt.py --out work/build/lyt_stage_I4` → 4개 교체·검증 OK (통합은 리드).

## 5. 정한 것 / 시도하고 버린 것
- 실루엣(마리오·루이지)을 원래 자리에 두면 1DX의 큰 「마」 위에 파묻힘 → 마·루 머리 글자 위에 세움(발 깊이는 원래와 같게).
- 1DX 로고의 지 위 새싹(1DX 콩 테마 장식)은 3DX에 맞지 않아 뺌.
- 층 모델에서 몸통 색을 k표(깊이)만으로 칠하면 적갈색 입체가 사라짐 → 입체 끝 사본까지의 거리 특징 추가. 번짐을 k-NN으로 하면 줄무늬 잡음 → 거리·법선 표로.
- 쿠파주니어: 한 줄 균일 배치(글자 29px)는 약해 보임 → クッパ/Jr.처럼 「쿠파」 크게·「주니어」 작게, 글자마다 ±3~5° 기울임.
  k-NN 링은 노란 선이 사라지고 얼룩 → 원본에서 잰 거리별 링 색표(흰 3px→노랑→적갈색, 위/아래 따로)로 칠함.
- 「デラックス」 자리 오른쪽 위 작은 흰 점(ス 위)은 옛 글자와 함께 지워짐.

## 6. 리드 확인
- 타이틀 로고 배치: 한국어 줄이 원본보다 왼쪽으로 약 12px 더 나감(유효 영역 x 31~393, 원본 43~393). 화면에서 잘리지 않는지 확인 필요.
- 「마리오」「루이지」 글자 높이가 RPG보다 약간 작음(본문 약 43px vs RPG 48px, 장평 81%) — 폭(RPG·3 위치 고정) 때문.
- 쿠파주니어 RPG: 1DX에 없는 주·니·어는 1DX 쿠파군단 글자의 획(폭 6px 직선 막대)으로 조립. 획 굵기 한국어 약 6px vs 일본어 8.5px
  (더 굵히면 ㅍ·ㅇ 속이 막혀 못 읽음) — 새 규칙 ±10% 밖. 루비 「ジュニア」는 한국어에서 뺌(주니어를 글자로 씀).
- 게임 시작 버튼 획 3.5px vs 원본 4px(-12%): 더 굵히면 「임」「작」 속이 막힘.
- 「Thank you for playing!」, ©표기, Ver. 1.2 는 영어 그대로(1DX 한국판도 같음).
- 층 순서 가정: 대조표의 타이틀 합성은 top 텍스처를 bottom 위에 얹은 모습(실제 모델 순서는 게임에서 확인).

# I5 — 스태프롤 진행 기록

## 형식 (확인됨)
- `Staffroll/JP/Staffroll.bin` = BLZ(BG4 항목과 같은 역방향 LZ) → `u32 줄 수` + 줄마다 96바이트: UTF-16LE 글자 44칸(NUL 끝) · u32 색 · f32 크기.
  - 3DX: 416줄. 색 0xFFFFFFFF = 흰색(이름), 0xFFA6C407 = 청록(역할; 메모리 바이트 07 C4 A6 FF). 크기 = 줄 높이(px): 이름 20, 역할 18, 제목 24, 빈 줄 60 등. 따로 된 타이밍 표는 없고 줄 수·순서·크기 합이 곧 스크롤 타이밍이다.
  - 1DX KR: 305줄, 같은 레코드 형식(색은 바이트 순서가 반대, 크기 값의 의미도 다름: 0 = 기본, 빈 줄 5/10).
  - BLZ 꼬리의 enc_len이 게임 파일은 파일 전체 길이, ndspy는 2 작다 → `libstaffroll.blz_pack`이 게임 값으로 써서 두 파일 모두 재압축 바이트 일치.
- 3DX 코드는 `RO/Field.cro`(v1.0·v1.2 모두)에서 `rom:/Staffroll/mario_font.bffnt`와 `rom:/Staffroll/JP/Staffroll.bin`만 읽는다. exefs2 `.code`·`static.crs`에는 경로 문자열이 없다(static.crs에는 `StaffrollCtrl` 심볼만).
- 폰트: 3DX `mario_font.bffnt` = 26×31 칸, A4 1시트(576칸 중 344 사용), KRNG 3,743쌍. 1DX `KR/mario_font_kr.bffnt` = 25×31, 기준선 24로 같고 KRNG 없음, 한글은 `루리마오이지` 6자뿐. 1DX kr 폰트의 영문 94자는 3DX 글리프와 픽셀까지 같고 폭(char)만 1px 좁다 → 같은 글꼴.

## 내용 결정
- 1DX 한국판 스태프롤은 제목 한 줄(「마리오&루이지 RPG 1 DX」)만 한국어이고 역할·부서·이름·저작권 문구는 모두 영어/로마자다. 따라서 3DX도 제목 #28만 「마리오&루이지 RPG3 DX」(IMAGE_TASK 0장 표기)로 바꾸고 나머지 415줄은 원본 그대로 둔다.
- 1DX KR에만 있는 NOK 현지화 크레디트 등은 넣지 않는다(크레디트를 새로 만들지 않음). 3DX에만 있는 사람도 원본이 이미 로마자라 옮길 것이 없다(공개 크레디트 확인 불필요).
- 두 게임에 모두 나오는 사람 중 철자가 다른 것(리드 확인): #291 `Galia Rodríguez Hornedo`(1DX `Galia Rodriguez Hornedo`), #288 `Ryan Kelley`(1DX `R Nathaniel Kelley`, 같은 사람인지 불확실). 원본 3DX 크레디트 그대로 두었다. 1DX 표기로 바꾸려면 `work/img/staffroll/staffroll.json`의 `ko`만 고치고 다시 빌드.

# 쿠파주니어 RPG 모드 선택 로고 — RPG 글자 편집 흔적 제거 (2026-10-30)

사용자 지적: 시작 메뉴(모드 선택)의 「쿠파주니어 RPG」 로고에 아직 편집티가 난다. 한글 글꼴과 RPG 글꼴은 유지하고, RPG 글자에 보이는 일본어 글자 잔재를 없애 자연스럽게 한다.

## 확인한 것

- 첨부 그림 `final.png`는 바탕화면 `ml3dx_kj_affinity/final.png`(2026-10-09 23:34, 클로드판)와 바이트까지 같다. 10-10 조립 **전** 그림이다. 확대 그림도 이 파일과 맞는다(4배 확대 비교 평균 차 12, 설치본과는 55).
- 게임이 읽는 그림(Azahar 정션 → `patch/`)은 10-10 조립본이었다(MLyt `cb172fbe…1664`). 첨부 그림에 보이는 R 왼쪽 「r.」 흔적(턱·노란 점·울퉁불퉁한 외곽)은 10-10 조립에서 커진 「어」 밑으로 이미 가려져 있다.
- 실제 게임 그림에 남아 있던 편집 흔적:
  1. **R과 P 사이 흰 지그재그 줄.** 바탕판에서 R 실루엣 밑을 흰색으로 비우고 분리한 R을 얹었다. R의 반투명 가장자리가 흰 바탕과 섞여 줄이 됐다. 원본에서는 두 글자의 적갈 외곽이 붙어 하나로 이어진다.
  2. **R 위·오른쪽 바깥선과 「어」 위로 보이는 왼쪽 줄기 바깥선이 원본과 1px쯤 다름.** 분리 R은 바깥선을 다시 그린 것이라, 원본의 기울어진 계단 가장자리와 다르다.

## 방법 (`build_natural.py`)

- 10-10 구성은 그대로 둔다: OA 한글 자형(1.18배, 4도, 같은 재질), 위·아래 바람 위치, 겹침 순서(바탕 → 위 바람 → 문구 → 아래 바람). 한글 글자는 같은 코드로 같은 값을 다시 그린다.
- 바탕판에서 R·P·분홍 별·클라운카 자리를 **일본판 원본 픽셀 그대로** 둔다. R 실루엣 밑을 비우지 않는다.
- 분리 R(`kj_R_faithful_20261010/R_clean.png`, 10-10 모서리 수정본)은 원본 R이 「Jr.」나 옛 아래 바람에 덮였던 곳(Z)에만 쓴다. 대부분 「어」와 옮긴 아래 바람 밑이다. 「어」와 아래 바람 사이로 보이는 R 왼쪽 다리 모서리는 10-10에 사용자가 지정한 직각 모서리 그대로다.
- 「어」 위로 보이는 R 왼쪽 줄기 바깥선(156~172행): 원본의 깨끗한 148~161행에서 가장자리를 재면 직선이다(기울기 0.085px/행, 직선 잔차 최대 0.07px). 이 선을 그대로 이어, 「r」이 닿은 67픽셀만 바꿨다(흰 배경 또는 같은 적갈 바깥선). 나머지는 원본 픽셀이다.

## 결과와 검사

- 설치본 대비 185픽셀이 바뀌었다. 범위는 x202~259, y143~201(R 자리)뿐이다. 한글 문구·바람·P·G·캐릭터·별은 그대로다(문구·바람이 완전히 덮는 픽셀은 바뀐 것이 없음).
- 검사(`build_natural.py`가 매번 확인):
  - Z 밖에서 보이는 R·P 픽셀은 일본판 원본과 같다(RGB565 기준).
  - R/P 사이(x236~251)에 원본보다 밝은 픽셀이 없다(흰 줄 없음).
  - R 줄기 왼쪽에서 보이는 픽셀은 모두 흰색이다(「Jr.」 흔적 없음).
- 다시 실행하면 같은 PNG가 나온다(바이트 일치).

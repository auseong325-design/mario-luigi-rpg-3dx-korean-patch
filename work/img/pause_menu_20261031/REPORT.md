# 스타 메뉴 항목 이름 통일 + 능력→스테이터스 (2026-10-31)

## 요청
1. 스타 메뉴(START) 아래 화면의 항목 이름 6개 글꼴이 들쭉날쭉하다. 「능력」은 1DX 한국판처럼 「스테이터스」로 바꾼다.
2. (같은 날 수정 지시, 최종) 일본판 항목 이름은 글꼴이 반듯하니, 아이템·장비·가이드 등 6개 전부를 예전 「배지」·「능력」의 글꼴과 크기로 맞춘다. 「스테이터스」 이름 변경은 유지한다.

## 원인 (측정)
`scripts/lyt_B.py`(2차 B조)가 두 가지 방식으로 만들었다.
- 아이템·장비·기록·가이드: 1DX 메뉴 그림 글자(둥근 그림 글씨)를 낱말마다 채움 상자 높이 13px에 맞춰 줄였다. 그런데 1DX 글씨는 받침 있는 음절(템·장·록)이 아래로 더 내려온다. 그래서 같은 크기의 1DX 글씨가 0.812(아이템·장비), 0.765(기록), 1.0(가이드)배로 따로 줄었다. 1DX 메뉴 그림의 ㅣ 세로획은 모두 11.27px로 같은 크기다. 가이드는 받침이 없어 상자가 낮아 1.0배가 되었고, 그만큼 크고 1px 낮게 나왔다.
- 배지·능력: 1DX 대사 비트맵 폰트 `font`를 em 13(0.867배)으로 줄여 그렸다. 글꼴 자체가 다르다.

## 최종 방식 (v2, 설치본)
- 6개 모두 옛 배지·능력과 같은 방식이다: `lyt_B.compose(it, [("font", 낱말, "font")], em=13, outline=1.85, stroke=2.4)`. 1DX 한국판 대사 비트맵 폰트 `font`(17×18, 한글 em 15)를 0.867배로 줄이고, 획을 2.4px로 굵힌 뒤(획 사이 1px 틈 유지) 3DX 검은 테두리 1.85px를 두르고 LA4로 저장한다. 가로는 x 40 가운데에 둔다.
- 바꾼 것은 세로 중심 하나다. lyt_B는 일본어 낱말 상자에서 중심을 잡아 11.5와 12.0이 섞였다. 이번에는 6개 모두 12.0(텍스처 가운데, 옛 배지와 같은 값)으로 맞췄다.
- 확인: lyt_B 원래 중심으로 그리면 옛 배지와 능력 PNG가 픽셀까지 그대로 나온다. 같은 방식이라는 뜻이다. 그래서 설치본 배지는 10-31 이전과 바이트까지 같다.
- 너비(채움): 아이템 37, 장비 24, 스테이터스 62, 기록 25, 배지 23, 가이드 39px. 사용 가능 폭은 75.3px이고, 장평이나 자간을 줄인 낱말은 없다.
- 대조표: `sheets/labels_4x.png`(일본판 | 10-31 이전 | 새 판), `sheets/menu_row.png`(메뉴 순서로 1배와 3배).

## 대사 (스테이터스)
- 스타 메뉴 항목을 이름으로 가리키는 배틀 가이드 2줄만 바꿨다. 각각 복사본이 있어 메시지는 4개다(1DX BtlGuide_09·09_0과 같은 표기).
  - `BMsg/b_sys#1066`·`Menu#498` BtlGuide_11: 「기본⑤: 능력에 대해」 → 「기본⑤: 스테이터스에 대해」
  - `BMsg/b_sys#280`·`Menu#122` BtlGuide_11_0: 「…스타 메뉴의 「능력」에서…」 → 「…「스테이터스」에서…」
- 능력치를 두루 이르는 ステータス 20줄(모든 능력 업, 쿠파주니어 가이드 등)은 DS 표기 「능력」을 그대로 둔다. 그 뒤 같은 날 쿠파주니어 가이드(KJGuide_*) 7줄은 사용자 지시로 「스테이터스」로 바꿨다(`work/review/kj_guide_status_20261031/REPORT.md`).
- 용어집: `text/glossary.tsv`와 `text/glossary_overrides.tsv`에 「ステータス」→「스테이터스」, 基本⑤：ステータスについて→기본⑤: 스테이터스에 대해 두 행을 넣었다. ステータス=능력 행 메모도 고쳤다. `merge_ko.py --check`: p3·p10 오류 0, 이번 변경으로 생긴 경고 0. `--merge`: 130배치, ko_final에서 바뀐 메시지는 위 4개뿐이다. `build_patch.py --out`: 7개 파일 중 BMsg.dat·Menu.msbt만 달라졌다. 풀어서 비교해도 위 4개 메시지만 다르다.

## 검증
- `build_pause_menu.py build`: 기준은 설치본 MLyt.dat이다. MENU_MAIN의 TOP_MENU_TEXT_1~6 텍스처 6개만 바꿨다. 그 밖의 SARC 파일과 항목은 모두 바이트가 같다. 각 텍스처는 같은 크기·헤더의 LA4이고, 새 PNG로 무손실 디코드된다(`build_verify.json`). 10-31 이전 MLyt.dat(14f0aa9a)과 비교하면 다른 파일은 TOP_MENU_TEXT_1·2·3·4·6이다. 배지(5)는 같다.
- 시험용 Azahar(`tools/azahar-test`, 시험 빌드 `pm20261031b` = 설치 패치 + 새 MLyt.dat + code.ips): 1번 파일을 불러와 START를 눌렀다. 스타 메뉴 6개 이름이 같은 글꼴·크기·높이로 나오고, 스테이터스가 칸 안에 들어간다. v1 시험(`pm20261031`)에서 가이드 → 배틀 기본 → 「기본⑤: 스테이터스에 대해」 목록과 1쪽 본문 「스타 메뉴의 「스테이터스」에서 확인할 수 있어요.」를 확인했다(대사 파일은 v2와 같다). 시험 뒤 세이브 3개는 사용자 원본과 같고, 시험 인스턴스는 `use-patch`(38파일)로 되돌렸다.

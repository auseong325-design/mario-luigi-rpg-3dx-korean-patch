# 마리오&루이지 글자 형태를 1DX로 통일 — 2026-10-08

사용자 요청: `&`를 포함한 「마리오&루이지」의 글꼴·형태를 1DX 한국 정발판과 같게 하고, 색과 광택은 3DX 것을 유지한다. 앞서 정한 두 실루엣의 위치와 DX·디럭스 중앙 정렬도 유지한다.

## 제작 결과

- 1DX 덤프에서 추출한 실제 타이틀 로고 `mg_map_title_logo_KR_ko`의 글자 면을 사용했다. 추출 이미지: `work/img/logo/src/1DX/kr_logo_rgba.png`.
- 「마·리·오·&·루·이·지」 전체를 하나의 좌표 변환으로 옮겼다. 가로·세로 배율은 모두 약 0.9095이며, 원래 글자 사이 간격과 상대 높이를 보존한다. 타이틀 공간에 맞추면서 장평을 따로 줄이지 않는다.
- 기존 획 0.6px 굵힘과 「지」의 기둥 머리 재설계를 이 타이틀에서 제거했다. `seg_1dx.syllables(fix_stem=False)`로 원래 골조를 사용한다. 이전부터 제외했던 새싹 장식은 계속 제외한다.
- 일본판 `&`의 픽셀을 복사하던 처리를 없애고 1DX `&`에 3DX 재질을 입혔다. 마리오의 복숭아·주황·빨강, 루이지의 연노랑·연두·초록, `&`의 흰색·청록 계열을 유지하며, 3DX에서 측정한 행 그라데이션·광택선·남색 테두리·입체면·글로우를 사용한다.
- 마리오 실루엣은 「리」 위, 루이지 실루엣은 「오」 위에 유지했다. 새 글자 면에 맞춰 발 위치만 정렬했다.
- DX·디럭스 영역의 픽셀과 배치는 직전 설치본과 동일하다. 윗줄과 DX 중심 차이는 0.5 텍스처 픽셀이다. 새 글자 오른쪽 끝에 맞춰 RPG·3은 직전보다 오른쪽으로 0.5 텍스처 픽셀 이동했다.
- 인트로에서 따로 등장하는 `&`도 같은 1DX 모양으로 제작했다. 이전에 수정한 두 메시의 조립 좌표는 그대로 사용한다.

IoU는 재표본화한 **글자 면의 모양** 대조 수치다. 색·재질은 3DX로 제작했으므로 1DX 색 픽셀과의 일치를 뜻하지 않는다. 화면 비교와 인트로 조립 그림은 정적 투영 미리보기이며 실제 게임 실행 결과가 아니다. 저장소 지침에 따라 Azahar는 실행하지 않았다.

검증 자료: `shape_verify.json`, `build_verify.json`, `preview_metrics.json`, `intro_preview_verify.json`, `install.json`.

## 재제작 경로

`donor_layout.py`가 원본 일곱 글자의 골조와 배치를 만든다. `work/img/title_layout_20261008/build_title.py`가 3DX 재질과 실루엣을 합성하고, 이 폴더의 `build_intro_amp.py`가 인트로 `&`를 만든다. `work/img/logo2/run_all.py`에도 두 제작 경로를 연결했으며 `--install` 시 새 인트로 `&`까지 빌드 입력에 복사한다. `scripts/build_fmdl.py`는 기존 인트로 좌표 수정 레시피를 계속 적용한다.

개별 Python 단계는 이 폴더의 `run_checked.py`로 제한 시간을 걸어 실행한다. 이번 작업에서는 `stage.py`, `scripts/build_fmdl.py`, `verify_shapes.py`, `verify_build.py`, `preview_title.py`, `preview_intro.py`로 제작·확인했다. 이 폴더의 `prepare.py`, `stage.py`, `verify_build.py`, `install.py`는 이번 변경 전후의 스냅샷·백업·설치를 다루는 도구다. 이후 재제작은 위의 제작 레시피와 `logo2/run_all.py --install`을 사용하며, 이번 백업을 덮어쓰도록 작업용 도구를 재실행하지 않는다.

메인 에이전트가 직접 수행했으며 서브에이전트와 원본 파일 수정은 사용하지 않았다.

## 원인과 최종 배치

이전 한글 타이틀은 일본어 단어가 쓰던 폭에 맞추기 위해 1DX 음절을 가로 0.695,
세로 0.94배로 제작했다. 따라서 글자 골조 자체가 가로로 약 26% 더 압축됐다.
마리오·루이지 실루엣은 키가 높은 「마」「루」 머리 위로 올라갔지만 타이틀 모델의
표시 위치는 일본판 그대로라 화면 위쪽에 잘렸다.

- 1DX의 공식 음절 마스크를 가로·세로 모두 0.94배로 다시 제작했다.
  가로만 늘린 기존 그림을 쓰지 않고, 기존 3DX 재질 모델로 면·광택·테두리·입체를 다시 렌더링했다.
- 한글 시작점을 텍스처 X=44에서 18로 옮기고, 넓어진 글자 뒤로 RPG와 숫자 3을
  함께 X +40.75 이동했다. RPG와 3의 모양 및 크기는 이전과 같다.
- 1DX 화면에서 실루엣이 높은 머리 글자 옆의 낮은 글자 위에 서는 방식을 적용했다.
  마리오는 「리」, 루이지는 「이」 위에 발이 닿도록 배치했다. 원래 실루엣의 모양과 크기를 유지했다.
- 윗줄과 DX·디럭스를 텍스처에서 아래로 10픽셀 옮겨 화면 위쪽 여백을 확보했다.
- DX·디럭스의 중심을 텍스처 X=256으로 맞췄다. 양자화된 윗줄 전체의 가시 영역 중심과
  차이는 0.5 텍스처 픽셀(첨부 화면 배율로 약 0.37 화면 픽셀)이다.

작업 레시피: `build_title.py`.

## 화면 검증의 범위

현재 설치본의 타이틀 텍스처와 사용자 스크린샷을 색이 뚜렷한 글자 면으로 등록해
텍스처→화면의 근사 배율을 측정했다. 가로 약 0.733, 세로 약 0.775이며,
이 배율의 변경 전 렌더링이 첨부 화면의 로고와 맞는 것을 그림으로 대조했다.

같은 배율을 수정본에 적용한 정지 상태 미리보기에서:

- 실루엣 면은 화면 Y 약 17.55~53.02에 들어온다.
- 윗줄의 가시 영역은 화면 좌우에 약 17픽셀 여백을 갖는다.
- DX·디럭스는 윗줄의 중앙 아래에 배치된다.

이 값은 첨부 화면에 맞춘 근사 투영 결과다. 에뮬레이터에서 게임을 실행해 카메라나
전체 타이틀 애니메이션을 검증한 것으로 표시하지 않는다.
비교 그림은 `title_before_after.png`(왼쪽 수정 전, 오른쪽 수정 후), 단독 그림은
`screen_after.png`이다. `screen_mapping.json`, `preview_metrics.json`에 측정값을 기록했다.

## 재빌드 유지

일반 `scripts/build_fmdl.py`는 현재 빌드 입력 PNG와 기존 인트로 좌표 레시피를 사용한다.
`work/img/logo2/run_all.py`에도 새 타이틀 레시피를 연결했으므로 전체 로고 제작을 다시
실행해도 최종 타이틀 두 장은 이 배치가 적용된다. 인트로 조각과 파일 선택 로고는
자기 기존 레시피로 제작한다. 넓어진 타이틀이 검토 그림에서 잘리지 않도록
`make_review.py`의 타이틀 가로 크롭을 텍스처 전체로 넓혔다.

모든 파이썬 실행은 타임아웃 래퍼를 사용한다.

```powershell
.venv\Scripts\python -X utf8 work/img/title_layout_20261008/run_checked.py render 180 work/img/title_layout_20261008/build_title.py
.venv\Scripts\python -X utf8 work/img/title_layout_20261008/run_checked.py rebuild 300 scripts/build_fmdl.py
```

`stage_inputs.py`, `verify_build.py`, `install.py`는 이번 수정 전 설치본을 검사하는
일회성 도구다. 이미 설치된 뒤 그대로 재실행하는 배포 도구로 사용하지 않는다.

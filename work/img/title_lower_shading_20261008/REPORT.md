# ㅣ 끝 복원과 타이틀 하단 음영 재제작 — 2026-10-08

사용자 요청: 「루이지」에서 잘린 ㅣ 윗부분을 첨부 로고의 둥근 형태로 채우되 색과 광택은 현재 3DX 스타일을 유지한다. 마리오·루이지 글자 아래 빨강·초록 음영은 3DX 일본판 원본의 색 변화를 참고하고, 무늬와 외곽 형태는 1DX에서 가져온다.

## 적용 내용

- 「지」의 ㅣ 끝에 남아 있던 새싹 제거 흔적을 복원했다. 사용자 첨부 로고의 「지」에서 둥근 ㅣ 윗부분을 추출해 기존 기둥 위에 합쳤다. 실제 변경된 1DX 원본 좌표 범위는 X 321~331, Y 37~43이다. 원래 기둥을 지우지 않고 파인 부분을 채웠다.
- 참고 로고에서는 모양만 가져왔다. 연두·청록 색이나 참고 로고의 광택 픽셀은 복사하지 않았으며, 새 면에는 기존 3DX 그라데이션·광택·가장자리 음영을 적용한다.
- 직전의 하단 음영은 새 한글에도 일본어 원본의 전역 행별 색 표를 적용했다. 글자의 바닥 높이가 다른데도 같은 화면 행에서 색이 바뀌어 띠를 붙인 느낌이 났다.
- 이번에는 1DX 로고의 실제 알파 외곽과 2차원 음영 무늬를 글자 전체와 같은 좌표 변환으로 옮겼다. 원본 무늬의 농도를 3DX 일본판에서 측정한 남색→자주·짙은 빨강, 남색→짙은 초록, `&`의 청록 음영 곡선으로 변환했다. 색면이 각 글자의 바닥 굴곡을 따라 이어진다.
- RPG와 숫자 3은 기존 일본판 픽셀과 위치를 계속 사용한다. DX·디럭스와 두 실루엣의 위치도 직전과 동일하다.

## 재제작 경로

`material.py`의 `donors()`가 첨부 참고 이미지로 ㅣ 끝을 채우고, `geometry_and_shading()`이 1DX 외곽·무늬와 3DX 색 표를 결합한다. `work/img/title_layout_20261008/build_title.py`에 연결해 두었으므로 `work/img/logo2/run_all.py` 전체 제작 경로에서도 유지된다. `model.render()`에 선택 인자 `ext_override`를 추가해 이 타이틀의 2차원 하단 음영만 덮어쓰며, 기존 호출은 같은 동작을 유지한다.

Python 단계는 `run_checked.py`로 제한 시간을 걸어 실행했다. `prepare.py`, `stage.py`, `verify_build.py`, `install.py`, `complete_install.py`는 이번 변경 전후의 스냅샷과 설치를 위한 도구이므로 기존 백업을 덮어쓰도록 재실행하지 않는다. 이후 제작은 위 레시피와 전체 제작 파이프라인을 사용한다.

서브에이전트 없이 메인 에이전트가 작업했다. 원본 게임 및 정발판 덤프는 수정하지 않았다.

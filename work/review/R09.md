# R09 교차 검토 기록 — 아이템·장비·배지·스페셜 어택 이름과 설명

담당: Item__p1 ~ Item__p6 (분류 합계 new 222 · edited 65 · ds 117 · short 171).
기준: glossary.tsv(현재 값), style_guide 5.1, DS BData(UItmE2·WearE·BadgeE·AItmE·AItmE2).

## 파일 전체에 대해 먼저 한 확인 (6배치 공통)
- 이름(N_/Ns_/F_ 319개): glossary 확정값과 전부 일치. 원문보다 넓은 이름 0개(모두 원문 폭 이하).
  같은 일본어 이름이 들어간 모든 배치의 메시지(Menu 상점·설명, b_sys 전투 문구, FMsg 포함)를 대조 → 다른 표기 0건
  (`スターウェア`↔`マスターウェア` 부분 일치 1건은 오탐). 한 한국어 이름이 두 아이템에 쓰인 경우 0건.
  띄어 쓴 변형(`가득 양말` 등)도 전체 text/ko에서 0건(`작은 방패`·`큰 방패`는 설명문 속 일반 명사라 정상).
- 장비 종류명·용어(양말/웨어/글러브/부츠/팔찌/반지/패치/액세서리, 방어 액션, 배지 게이지, 배지 파워, 럭키 히트,
  선제공격, 분노 상태, 어질어질, 빈사, 블로크, 블캐츠, 바디프레스): Item 밖 모든 배치에서 원문에 있으면 번역에도 있음(누락 0건).
- 설명문 형식: 끝 부호(。→`.`, ！→`!`), 문장 수, 줄 수 모두 원문과 같음. 배지 설명 E_Badge00~09 10개 모두 `.`으로 끝남.
  스페셜 어택 설명 16개 모두 끝줄 `공격 대상: X   효과: Y`(반각 공백 3칸) 형식. 숫자는 원문과 모두 같음(１体→하나 등 의도된 것 제외).
- 설명 문장의 アップ=`증가`, 이름·상태의 アップ=`업`(POW 업 상태, 파워 업) — glossary 주석대로 일관. 배지 효과 `POW 20% 업.`(EFF_Badge_01_06·08)은
  b_sys `클리어 후 EXP {var}% 업!`(#413·#1145·#1167·#1189)과 같은 꼴이라 그대로 둠.
- review_items 'Item:' 항목 판단: `공격 대상: 랜덤`(3DX ランダム, 7곳), `효과:` 앞 공백 3칸, 自由に設定=`자유 설정`, 배지 설명 끝 마침표,
  Item#188 `「특수 효과 없음」`(반각 []는 태그 문법이라 불가, 전각 ［］는 폰트에 없음) — 모두 그대로 둬도 됨. 파일 안에서 일관됨.

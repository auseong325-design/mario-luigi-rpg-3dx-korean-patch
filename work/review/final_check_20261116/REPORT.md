# 배포 전 최종 확인 (2026-11-16)

## 요청
배포 전에 번역 상태를 마지막으로 확인한다. 네 가지를 본다.

1. 원작 DS판 번역을 잘 따르는지
2. 리메이크에서 바뀐 부분을 반영했는지
3. 새로 번역한 쿠파주니어 RPG가 본편(마리오&루이지 RPG3)과 어울리는지
4. 글자가 칸을 벗어나거나 충돌을 일으키지 않는지

10-31 최종 검토(`work/review/final_20261031/`)는 같은 일본어의 다른 번역, 용어집, 띄어쓰기, 맞춤법을 기계로 훑었다. 이번에는 그때 쓰지 않은 방법을 썼다.

- DS 줄을 방 순서로 대조했다.
- DS와 다른 글자를 한 건씩 판정했다.
- 두 모드의 호칭과 말버릇을 대조했다.
- 실제 폰트로 줄 폭을 다시 쟀다. 큰 글씨 구간, 코드에서 확인한 폰트 표, 레이아웃 칸 크기를 반영했다.

## 결론

- 네 항목 모두 큰 문제는 없다.
- 고친 것은 칸 폭 3건이다. 메시지 3개, 파일 3개(FMsg.dat·BMsg.dat·Menu.msbt)가 바뀌었다.

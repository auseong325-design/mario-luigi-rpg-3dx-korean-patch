## 최종 적용

마지막 재개 이후 메인이 직접 작업했다. SS컴퍼니는 사용자 확정대로 **슬림·큐티·마초**, 슬림의 애칭은 **슬림씨**로 통일했다. 이름이 바뀌는 대표 문장 29개와 관련 메모·용어집·배치 내 용어 자료를 갱신했다. 용어집 override에도 기록해 재생성할 때 이전 이름으로 돌아가지 않게 했다. 큐티는 기존 이름과 같다.

마초 이름에 연결된 `k_o_ekubon_80#21`의 말장난은 「마초는? / 마…마…몰라…」로 바꾸고, 다음 「무지는 죄라네」와 이어지게 했다. 이름 변경과 직접 연결된 이 부분 외에 사용자 보류 표현 2개는 유지했다.

1DX 한국판에서 확인한 이기의 1인칭 「나/내」를 7개 대표 문장(인용 포함)에 적용했다. 레미의 짧은 웃음도 1DX에서 직접 설명한 「케케케」 계열에 맞춰 「케케」로 교정했다. 복사본을 포함해 말투 변경 12 ID다. 상세 근거는 `kj_speech.md`와 `kj_speech_1dx_evidence.tsv`에 있다. 해당 보고서의 SS 이름은 이번 사용자 지정 전 기록이며 현재 이름은 이 문서와 glossary가 우선한다.

본편 신규 대사와 오리지널 캐릭터 문체는 현행 유지가 적절했다. 슬림은 까르코비츠에게 정중체·적에게 연극조 반말, 큐티는 평소 애교 말투·분노 때 반말, 마초는 짧은 단문을 유지한다. 루드윅이 마초로 변장한 장면은 루드윅의 말투와 구분한다. 지하 본편 2문장은 DS 이벤트의 같은 작업 지휘자에게 연결돼 현행 반말을 유지했다. 나머지 미확정 발화자를 임의로 확정하지 않았다.

후리가나 설정은 v1.2 `RO/MainMenu.cro`의 기존 비일본어 경로로 숨겼다. 실행 코드 1바이트와 필요한 CRO/CRR 해시만 수정했다. 기존 애니메이션이 행·배경을 숨기고 다른 행을 재배치하며, 커서도 숨긴 행을 건너뛴다. 실제 ARM 명령의 조건·커서 이동·초기 선택·버튼 활성 처리를 검사했다. 자세한 구조·서명 제약은 `furigana.md`에 기록했다. 실제 게임 실행으로 화면을 확인했다는 뜻은 아니다.

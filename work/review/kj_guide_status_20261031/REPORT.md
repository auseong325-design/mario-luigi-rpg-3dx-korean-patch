# 쿠파주니어 가이드: ステータス → 「스테이터스」 (2026-10-31)

## 요청
쿠파주니어 가이드의 「능력」도 「스테이터스」로 바꾼다. 같은 날 스타 메뉴 항목과 배틀 가이드 「기본⑤」를 「스테이터스」로 바꾼 데 이어지는 작업이다(`work/img/pause_menu_20261031/REPORT.md`).

## 범위
- 쿠파주니어 RPG 가이드(라벨 `KJGuide_*`)에서 일본어 ステータス를 「능력」으로 옮긴 7줄을 바꿨다. 모두 `BMsg/b_sys`에 있고 복사본은 없다.
- 1DX 한국판 쿠파군단 RPG 가이드(`KGGuide_*`)도 「스테이터스」를 쓴다. 근거: `KGGuide_BB05` 「스테이터스에 대해」, `KGGuide_BB05_0`, `KGGuide_O05_2` 「캐릭터의 스테이터스를」.
- 문장은 그대로 두고 낱말과 조사만 바꿨다(능력이→스테이터스가, 능력은→스테이터스는, 능력을→스테이터스를). 가이드 본문의 해요체(style_guide 5.1)도 유지했다.

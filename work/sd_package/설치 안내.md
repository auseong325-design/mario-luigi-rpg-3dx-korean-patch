# 마리오&루이지 RPG3 DX 한글패치 설치 안내

2026-11-16판 · 배포 파일: `ml3dx_ko_luma.zip`

일본판 『マリオ&ルイージRPG3 DX』를 한국어로 즐길 수 있게 하는 비공식 패치입니다.
본편 이야기와 「쿠파주니어 RPG」의 대사, 메뉴, 그림 속 글자, 타이틀 로고가 한국어로 나옵니다.
New 3DS에서 더 부드럽게 움직이는 60fps 모드도 들어 있습니다. 필요 없으면 끌 수 있습니다.

## 요약

- 3DS 본체: ZIP 안의 `luma` 폴더를 SD 카드 맨 위에 복사하고, Luma3DS 설정에서 「Enable game patching」을 켭니다.
- PC(Azahar): 게임을 오른쪽 클릭 → 「열기」 → 「Mods Location」으로 연 폴더에 `romfs` 폴더와 `code.ips` 파일을 복사합니다.
- 60fps 끄기: `code.ips` 파일 하나만 지웁니다.
- 직접 복사하기 어렵다면: [3DS 한글패치 매니저](https://github.com/auseong325-design/3ds-patch-universal-tool/releases)에 ZIP을 끌어다 놓아 설치할 수 있습니다(9번).

## 1. 준비

- **일본판 게임**이어야 합니다. 게임 카드로 해도, 다운로드판이어도 됩니다. 북미판·유럽판에는 쓸 수 없습니다.
- **업데이트 Ver. 1.2**가 꼭 설치돼 있어야 합니다. 게임을 켰을 때 타이틀 화면(위 화면) 오른쪽 아래에 「Ver. 1.2」가 보이면 됩니다. 업데이트가 없으면 패치를 넣은 게임이 켜지지 않거나 멈춥니다.
- 플레이 환경은 둘 중 하나입니다.
  - 3DS 본체: Luma3DS(커스텀 펌웨어)가 설치돼 있어야 합니다. Luma3DS 설치 방법은 이 안내에서 다루지 않습니다.
  - PC: 에뮬레이터 Azahar
- 처음 설치할 때는 만약을 위해 세이브를 백업해 두면 좋습니다(3DS 본체는 Checkpoint 등).

## 2. 3DS 본체에 설치하기 (Luma3DS)

1. 3DS 전원을 끄고 SD 카드를 PC에 연결합니다.
2. `ml3dx_ko_luma.zip`을 열면 `luma` 폴더 하나가 보입니다. 이 `luma` 폴더를 SD 카드 맨 위(SD 카드를 열었을 때 바로 보이는 곳)에 복사합니다.
   - SD 카드에 이미 `luma` 폴더가 있어도 그대로 복사하면 됩니다. 폴더가 합쳐지고, 원래 있던 설정은 지워지지 않습니다.
   - 압축 프로그램의 「(파일 이름)\에 풀기」처럼 폴더를 한 겹 더 만드는 방식은 쓰지 마세요.
3. 아래처럼 들어갔는지 확인합니다.

   ```
   SD 카드
   └─ luma
      └─ titles
         └─ 00040000001CA900
            ├─ code.ips    (60fps 모드)
            └─ romfs       (한글 파일)
   ```

4. SD 카드를 3DS에 다시 넣고, **SELECT 버튼을 누른 채로** 전원을 켭니다. Luma3DS 설정 화면이 나옵니다.
5. 십자 버튼으로 「( ) Enable game patching」을 고르고 A 버튼을 눌러 켭니다(괄호 안에 표시가 생깁니다). START 버튼을 누르면 저장되고 평소처럼 켜집니다. 이 설정은 한 번만 하면 됩니다.
6. 게임을 켭니다. 타이틀 로고가 한글 「마리오&루이지 RPG3 DX」로 나오면 성공입니다.

## 3. PC(Azahar)에 설치하기

메뉴 이름은 Azahar 한국어 화면 기준이고, 괄호 안은 영어 화면의 이름입니다. 일부 메뉴는 한국어 화면에서도 영어로 나옵니다.

1. 본편과 업데이트(Ver. 1.2)를 Azahar에 설치합니다: 「File」 → 「CIA 설치하기...」(Install CIA...). 이미 설치했다면 넘어갑니다.
2. 게임 목록에서 게임을 오른쪽 클릭하고 「열기」(Open) → 「Mods Location」을 누릅니다. 이 게임의 모드 폴더가 열립니다.
3. `ml3dx_ko_luma.zip` 안의 `luma` → `titles` → `00040000001CA900` 폴더로 들어가서, 그 안의 `romfs` 폴더와 `code.ips` 파일을 2번에서 연 폴더에 복사합니다.

   ```
   (모드 폴더) …\load\mods\00040000001CA900
   ├─ code.ips
   └─ romfs
   ```

4. 게임을 켭니다(이미 켜져 있었다면 껐다가 다시 켭니다). 타이틀 로고가 한글로 나오면 성공입니다.

2번 메뉴를 못 찾으면, 탐색기 주소창에 `%APPDATA%\Azahar`를 입력해 들어간 뒤 `load\mods\00040000001CA900` 폴더(없으면 만듭니다) 안에 복사해도 됩니다.

## 4. 60fps 모드

- 설치하면 처음부터 켜져 있습니다.
- **New 닌텐도 3DS · New 닌텐도 3DS XL · New 닌텐도 2DS XL**에서만 60fps로 움직입니다. 이전 모델(닌텐도 3DS · 3DS XL · 2DS)에서는 자동으로 원래 속도(30fps)로 돌고, 한글은 그대로 나옵니다.
- **끄기:** `00040000001CA900` 폴더의 `code.ips` 파일 하나만 지웁니다. 다른 곳에 옮겨 두면 나중에 다시 쓸 수 있습니다. 나머지 파일은 그대로 둡니다.
- **다시 켜기:** `code.ips`를 같은 자리(`romfs` 폴더 옆)에 다시 넣습니다.
- 윈도우가 파일 확장자를 숨기는 설정이면 `code.ips`가 `code`로만 보일 수 있습니다.
- Azahar에서는 창 아래 상태 표시줄에 「App: 60 FPS」가 나오면 60fps입니다. 30으로 나오면, 게임을 끈 상태에서 「에뮬레이션」(Emulation) → 「설정...」(Configure...) → 「시스템」(System)의 「New 3DS mode 활성화」(Enable New 3DS mode)가 켜져 있는지 확인합니다. 기본값은 켜짐입니다.
- 미니게임, 보스의 버티기 공격, 스타&스타, 엔딩 크레딧은 60fps에서도 원래 속도로 움직이게 맞췄습니다. 장비 화면·상점의 화면 전환, 메뉴에서 버튼을 누르고 있을 때 커서가 넘어가는 속도 같은 일부 연출은 조금 빠릅니다. 원래 60fps인 『마리오&루이지 RPG1 DX』와 같은 속도입니다.
- 인터넷에 있는 60fps 치트를 쓰고 있었다면 꺼 주세요. 이 패치에는 필요 없고, 치트 기능은 장면이 바뀔 때 게임이 멈추는 원인이 될 수 있습니다.
- 한글 없이 60fps만 쓰고 싶다면 `code.ips`와 `romfs\BAI\BAI.dat` 두 파일만 같은 자리에 넣습니다.

## 5. 새 버전으로 바꾸기 · 패치 지우기

- **새 버전으로 바꿀 때:** 먼저 기존 `00040000001CA900` 폴더를 통째로 지운 뒤, 새 파일을 위 방법대로 넣습니다. 그 위에 덮어쓰면 지워져야 할 옛 파일이 남을 수 있습니다.
- **패치 지우기:** `00040000001CA900` 폴더를 지우면 원래 일본어 게임으로 돌아갑니다.
- 패치는 세이브 파일을 바꾸지 않습니다. 일본어로 하던 세이브를 그대로 이어서 할 수 있습니다.

## 6. 문제가 생기면

**일본어 그대로 나와요**
- 3DS 본체라면 Luma3DS 설정의 「Enable game patching」이 켜져 있는지 확인합니다.
- 폴더 위치를 확인합니다. `SD:\luma\titles\00040000001CA900\romfs`여야 합니다. 중간에 폴더가 한 겹 더 있으면(예: `SD:\ml3dx_ko_luma\luma\…`) 게임이 읽지 못합니다.
- Azahar라면 모드 폴더(`…\load\mods\00040000001CA900`) 바로 안에 `romfs` 폴더와 `code.ips`가 있어야 합니다. `luma` 폴더째 넣으면 읽지 못합니다.
- 일본판인지 확인합니다. 북미판·유럽판은 폴더 이름이 달라서 패치가 적용되지 않습니다.

**게임이 켜지다가 멈추거나 꺼져요**
- 업데이트 Ver. 1.2를 확인합니다. 패치를 잠시 빼고(폴더 이름을 바꾸거나, 3DS 본체라면 「Enable game patching」을 끄고) 게임을 켜서 타이틀 화면의 「Ver. 1.2」를 봅니다.
- `00040000001CA900` 폴더에 `code.bps` 파일이 있으면 지웁니다. 예전 시험판에 들어 있던 파일입니다.
- Luma3DS가 오래된 버전이면 최신 버전으로 바꿔 봅니다.
- 그래도 멈추면 `code.ips`만 빼고(30fps) 켜 봅니다. 이때 정상으로 켜지면 60fps 쪽 문제이니 알려 주세요.

**HOME 메뉴의 게임 이름과 그림이 일본어예요**
- 정상입니다. 이 패치는 게임이 읽는 파일을 바꾸는 방식이라, HOME 메뉴에 보이는 이름과 그림은 바꿀 수 없습니다.

**가이드를 볼 때 위 화면이 비어 있어요**
- 원래 게임도 같습니다. 패치 문제가 아닙니다.

## 7. 알아 두기

- 닌텐도와 관계없는 비공식 팬 패치입니다. 게임은 들어 있지 않으며, 직접 가지고 있는 게임에 덧씌워 쓰는 파일입니다.
- 일본판 Ver. 1.2 전용입니다.
- 번역은 DS판 『마리오&루이지 RPG3』 한국어판을 바탕으로 했고, 글꼴과 로고 글자는 3DS판 『마리오&루이지 RPG1 DX』 한국어판의 것을 바탕으로 했습니다.
- 확인한 환경: Azahar 2126.1.2(Windows PC), New 3DS 계열 본체 + Luma3DS v13.4.

## 8. 3DS 한글패치 통합 툴로 통합판 만들기

이 절은 위의 `ml3dx_ko_luma.zip`을 그대로 설치하는 사람에게는 필수가 아닙니다. 본인이 보유한 일본판 본편과 Ver. 1.2 업데이트를 한 게임 파일로 합치거나, 한글패치 배포 파일을 다시 만들 때 사용하는 별도 방법입니다.

게임 파일은 출처와 관계없이 일본판이어야 하며, 통합 패키지의 기준 원본과 내부 파일이 맞아야 합니다. 맞지 않으면 툴이 해시 불일치로 중단할 수 있습니다. ZIP·7z에 들어 있는 게임 파일은 먼저 압축을 풀어 주세요.

키 파일이 모든 경우에 필요한 것은 아닙니다. 기존 한글패치 ZIP을 SD 카드에 복사할 때는 필요 없고, 복호화된 게임으로 CCI를 만드는 시험에서도 필요하지 않았습니다. 다만 현재 툴에서 CIA를 만들 때는 필요한 키와 `certs.bin`을 준비해야 합니다.

이 PC의 통합 툴은 `C:\AI-Projects\3ds-patch-universal-tool`에 있습니다. [통합 툴 상세 설명서](../../../3ds-patch-universal-tool/upstream/TranslationToolkit/README_KO.md)와 [실행 파일](../../../3ds-patch-universal-tool/upstream/TranslationToolkit/3DS%20한글패치%20매니저%20실행.bat)은 같은 `AI-Projects` 폴더 구조에서 열 수 있습니다. 다른 PC에 이 안내서만 복사하면 해당 경로의 툴은 함께 설치되지 않습니다.

### 기존 ZIP과 통합판의 차이

- **위의 LayeredFS ZIP:** 원본 일본판 본편에 공식 **Ver. 1.2 업데이트를 설치**한 뒤, ZIP의 `romfs`와 `code.ips`를 별도로 설치합니다. 60fps를 끄려면 위 4절처럼 `code.ips`를 빼면 됩니다.
- **본편에 업데이트를 합친 통합판:** 통합 툴로 원본 본편에 v1.2 코드와 파일, 한글패치, 선택한 60fps 코드와 HOME 배너를 반영해 CCI·CIA·ZCCI를 만듭니다. 이 게임에서 공식 v1.2 업데이트가 별도로 설치돼 있으면 업데이트가 통합 본편보다 우선해 60fps와 한글 타이틀 로고, 후리가나 숨김이 빠지는 현상을 Azahar에서 확인했습니다. 실기에서도 업데이트가 우선할 것으로 보지만 통합 CIA를 실기에서 확인하지는 못했습니다. 통합판 시험은 **별도 공식 업데이트 없이** 진행했습니다. 통합판과 기존 LayeredFS 패치를 함께 두면 파일이 겹칠 수 있으므로 어떤 패치가 적용되는지 확인하세요.

통합판에 60fps 코드를 **직접 포함해 만들었다면**, 위 4절처럼 `code.ips` 파일 하나를 빼는 것만으로는 통합된 코드를 끌 수 없습니다. 켜고 끌 수 있게 하려면 ① 통합 패키지를 만들 때 업데이트 코드용 IPS를 선택하지 않아 30fps 한글 통합판을 만들고, ② 기존 60fps 파일 두 개(`code.ips`와 `romfs\BAI\BAI.dat`)를 별도 모드로 설치합니다. 이 경우 별도 모드의 `code.ips`를 빼서 60fps를 끌 수 있습니다. 이 조합은 Azahar에서 확인했고, 실기에서는 아직 확인하지 못했습니다.

### 통합 툴에서 만들기

1. [통합 툴](../../../3ds-patch-universal-tool/upstream/TranslationToolkit/README_KO.md)을 실행합니다. Python 3.10 이상과 Tkinter가 필요하고, RomForge 추출·리팩에는 .NET 10 런타임이 필요합니다. xdelta 실행 파일이 없으면 툴의 **xdelta 설치 (Windows x64)** 버튼으로 준비합니다.
2. **프로젝트 및 빌드** 탭에서 직접 보유한 일본판 본편 게임 파일을 선택하고, **RomForge 리팩** 탭에서 키 파일 폴더를 지정한 다음 **원본 게임에서 번역 작업 폴더 준비**를 누릅니다. 같은 방법으로 Ver. 1.2 업데이트 게임 파일의 작업 폴더도 별도로 만듭니다. 이 프로젝트의 복호화된 CIA를 읽는 시험에서는 빈 키 폴더를 사용했습니다. 암호화된 콘텐츠와 CIA 출력에는 필요한 개인 키가 있어야 합니다.
3. **업데이트 통합** 탭의 본편·업데이트 작업 폴더를 확인합니다. **번역 패치 RomFS 폴더**에는 이 프로젝트의 `patch\00040000001CA900\romfs`를 지정합니다. 60fps를 통합하려면 **업데이트 코드용 IPS**에 `patch\00040000001CA900\code.ips`를 지정합니다. HOME 배너를 포함하려면 **교체 HOME 배너**에 `work\banner_20261030\out\banner\banner_ko.bin`을 지정합니다. IPS는 해당 업데이트 코드용인지 직접 확인해야 합니다.
4. **본편 기준 통합 xdelta 패키지 생성**을 누릅니다. 이 패치의 시험 패키지는 약 6.5MB였으며, 변경 RomFS 39개와 코드·확장 헤더·배너의 본편 기준 차분을 담았습니다. 받는 사람은 자기 본편에서 준비한 작업 폴더와 패키지를 사용해 **통합 패키지를 본편에 적용 및 리팩**을 누릅니다. 미리 만들어진 통합 패키지를 적용할 때는 업데이트 파일을 따로 준비하지 않아도 됩니다. 이 ZIP은 통합 툴 전용이며 RomForge 앱에서 바로 여는 패키지는 아닙니다.
5. 출력 형식은 **RomForge 리팩** 탭에서 고릅니다. CCI·ZCCI는 Azahar용, CIA는 실기 설치용입니다. CIA를 만들려면 필요한 키와 `certs.bin`을 사용자가 준비해야 합니다. 원본을 읽거나 저장할 위치는 충분한 빈 공간이 있어야 하며, 원본 게임 폴더에는 결과물을 쓰지 않습니다.

도구는 원본 파일 해시와 리팩한 파일의 해시를 확인하지만, 그 자체로 게임 실행을 보장하지는 않습니다. CCI는 Azahar 시험기에서 확인했고, 결과 RomFS 1,282개와 해시도 독립 검사했습니다. 통합 CIA 생성과 실기 실행은 필요한 키가 없어 확인하지 못했습니다. 자세한 시험 결과와 제한은 [통합 툴 실사용 검토](../review/dist_tool_20261031/REPORT.md)의 「재검토」 절에 있습니다.

## 9. 프로그램으로 설치하기 (선택)

파일을 직접 복사하는 대신 [3DS 한글패치 매니저](https://github.com/auseong325-design/3ds-patch-universal-tool/releases)의 「초간단 모드」로 설치할 수 있습니다. 넣어 주는 파일과 위치는 2번·3번에서 직접 복사한 것과 같습니다. 1번의 준비물(일본판 게임과 업데이트 Ver. 1.2)은 똑같이 필요합니다.

1. 위 링크의 릴리스에서 Windows용 ZIP을 받아 모두 압축을 풀고, `3DS 한글패치 매니저 실행.bat`를 실행합니다.
2. `ml3dx_ko_luma_20261116.zip`을 **압축을 풀지 않은 채로** 창에 끌어다 놓습니다. 「바로 설치하는 패치」라고 나오면 맞게 인식된 것입니다.
3. 플레이할 곳을 고릅니다.
   - 「닌텐도 3DS」: PC에 연결한 SD 카드를 찾아 줍니다. 못 찾으면 「폴더 직접 고르기」로 SD 카드를 고릅니다.
   - 「PC」: Azahar 폴더를 찾아 `load\mods\00040000001CA900`에 넣습니다. 본편과 업데이트는 3번의 1단계처럼 Azahar에 먼저 설치해 두어야 합니다.
4. 「설치 시작」을 누릅니다. 끝나면 「폴더 열기」로 들어간 파일을 확인할 수 있습니다.
5. 3DS 본체라면 2번의 4~6단계(「Enable game patching」 켜기)를 이어서 합니다.

- 같은 판이 이미 들어 있으면 아무것도 바꾸지 않습니다. 이전 판이나 다른 파일이 들어 있으면 먼저 물어본 뒤, 기존 `00040000001CA900` 폴더를 지우지 않고 `luma\titles_backup`(Azahar는 `load\mods_backup`)으로 옮기고 새로 넣습니다.
- 60fps를 끄려고 `code.ips`를 지워 둔 상태에서 다시 설치하면 `code.ips`도 다시 들어갑니다. 4번처럼 한 번 더 지워 주세요.
- 프로그램은 Windows 64비트용 사전 공개 버전입니다. 잘 되지 않으면 2번·3번의 방법으로 직접 복사하세요.
